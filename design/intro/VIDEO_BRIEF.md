# 인트로 영상 제작 안내 — 대표가 직접 만들 경우

> 디자인 실장 · 2026-11-28. 추천 콘셉트는 ② 「복자가 문을 연다」다(평가는 `REVIEW.md`).
> 세계관은 두 가지 중 대표 결정(A4)에 따른다.
> - **가안 = 한지 미닫이 + 찻상 + 등잔**(`door.html`)
> - **나안 = 수선집 간유리 미닫이 + 재봉틀 + 줄자 + 노란 실**(`door-sewing.html`)
>
> 장면 구성은 같다. 코드 시안이 그대로 '콘티'다. 브라우저에서 `door.html?fresh=1&cut=full`로 열고 `?at=1500`처럼 시각을 넣으면 그 순간에 멈춘 장면을 볼 수 있다.

## 1. 만들 것 (세 벌)

| 이름 | 쓰는 곳 | 길이 | 비율·크기(원본 → 웹용) |
|---|---|---|---|
| **사이트 압축판** | 첫 방문 첫 화면(1회 재생 후 마지막 장면에서 멈춤) | **2.5~3초** | 9:16 1080×1920 → 720×1280 / 16:9 1920×1080 → 1280×720 |
| **반복판** | 숏폼(릴스·쇼츠), 광고, 앱 소개, 공유 | **6~8초, 처음과 끝이 이어지는 반복** | 9:16 1080×1920 / 16:9 1920×1080 |
| **포스터 이미지** | 영상이 뜨기 전·저데이터·움직임 줄이기 | 정지 화면 | 각 비율의 **첫 프레임** 1장 + **마지막 프레임** 1장 |

- 사이트 휴대폰 화면에서는 **아래쪽 약 40%가 HTML 글자·버튼에 덮인다**(문장, 시작 버튼, 고지). 그래서 문·복자·할머니 같은 중요한 움직임은 화면 **위쪽 60% 안**에 둔다. 사이트 전용으로 4:5(1080×1350)를 따로 뽑아도 좋다.
- 숏폼 9:16도 위 14%·아래 35%가 앱 버튼에 가려질 수 있다는 주장이 있다(트렌드 조사, 검증 안 됨). 핵심 장면은 가운데에 둔다.

## 2. 장면 구성 (초 단위)

### 2-1. 반복판 7초
| 시간 | 장면 | 화면에서 꼭 보일 것 |
|---|---|---|
| 0.0–0.5 | 닫힌 미닫이. 안쪽 불빛이 문종이(간유리)에 따뜻하게 일렁임. 아래쪽에 고양이 그림자 | **첫 프레임만 봐도 '불 켜진 방, 고양이'가 읽힐 것**(포스터가 된다) |
| 0.5–1.4 | 그림자가 짧은 걸음 네 번으로 문 가운데 틈 쪽으로 걸어옴 | 걷는 연기(코드판에는 없음) |
| **1.4–2.0** | 문틈이 한 뼘 열리며 **복자 머리가 쑥**. 귀 한쪽을 턴다. 나안은 입에 노란 실 | **후킹 지점. 늦어도 1.7초 안** |

| 6.2–7.0 | 문이 스르르 다시 닫히고 그림자만 남음 → 첫 프레임과 이어짐 | 이음매 없는 반복 |

## 3. 파일 규격
- **MP4(H.264)**: High 프로필, yuv420p, 24 또는 30fps, `faststart`(재생 정보를 파일 앞에 둬 바로 재생). **오디오 트랙은 아예 넣지 않는다**(무음 트랙도 빼기).
- **WebM(VP9)**: 같은 내용. 브라우저가 둘 중 가벼운 것을 고른다.
- 용량:
  - 사이트 압축판: 휴대폰 **600KB 이하 목표**(상한 2MB), PC 1.5MB 이하.
  - 반복판: 휴대폰 **2MB 이하 권장**, 숏폼 업로드용 원본은 용량 제한 없이 고화질.
- 그림체가 납작한 면 위주라 비트레이트를 낮춰도 잘 버틴다. 등잔빛 같은 **번짐(그라데이션)은 줄무늬(밴딩)가 생기기 쉬우므로**, 아주 옅은 질감을 넣거나 번짐 면적을 줄인다.
- 포스터: WebP 60KB 이하 + JPG 예비본. 첫 프레임과 마지막 프레임, 비율마다 각각.
- 색: sRGB. 브랜드 색 값은 `design/tokens.css` 시안 B를 쓴다.
  - 한지 #f3eadb, 먹 #221e1b, 복자 노랑 #f2c14e, 나무 #a8784a / #7a5233, 저고리 #6d8a6a, 고름 #c8693f.
- 파일 이름 예: `intro-door-9x16-short.mp4`, `intro-door-9x16-short.webm`, `intro-door-9x16-poster-first.webp`, `intro-door-16x9-loop.mp4`. 받은 파일은 디자인 실장이 `public/brand/intro/`에 정리한다.

## 4. 사이트에 넣는 방식 (프론트엔드 담당 구현 기준)
```html
<video autoplay muted playsinline preload="metadata"
       poster="/brand/intro/intro-door-9x16-poster-first.webp" aria-hidden="true">
  <source src="/brand/intro/intro-door-9x16-short.webm" type="video/webm">
  <source src="/brand/intro/intro-door-9x16-short.mp4" type="video/mp4">
</video>
<!-- 문장·시작 버튼·고지·건너뛰기는 영상 밖 HTML 글자로 둔다(0초부터 보임) -->
```
1. **자동재생 무음 + `playsinline`**은 휴대폰 자동재생 조건이다. 사이트 압축판은 `loop` 없이 1회 재생하고 마지막 프레임에서 멈춘다(`ended`에서 마지막 포스터로 바꿔도 된다).
2. **건너뛰기**(0초부터, 44px 이상)를 누르면 영상을 멈추고 마지막 프레임을 보여 준다. 시작 버튼은 영상과 상관없이 처음부터 누를 수 있다.
3. **첫 방문만 재생**하고, 재방문은 마지막 프레임 이미지나 코드 인트로 끝 장면을 보여 준다(코드 시안과 같은 `localStorage` 키).
4. **저데이터 모드**일 때 영상을 받지 않고 포스터만 보여 준다.
   - 조건: `navigator.connection.saveData` 또는 `effectiveType`이 `2g`·`slow-2g`(지원 브라우저만).
5. **움직임 줄이기**(`prefers-reduced-motion: reduce`)일 때 영상을 넣지 않고 **마지막 프레임**을 보여 준다.
6. **영상이 1초 안에 재생을 시작하지 못하면**(느린 망, 아이폰 저전력 모드에서 자동재생 막힘) 포스터 또는 코드 인트로를 그대로 둔다. 재생 단추를 띄우지 않는다.
7. 영상에는 장면 설명이 필요 없도록 `aria-hidden`을 쓰고, 같은 뜻의 문장은 HTML에 있다.

## 5. 금지 사항
- **글자를 영상에 굽지 않는다.** 문장·버튼·고지는 HTML에 둔다. 숏폼판 자막은 예외이며 voice-guide 말투를 따른다.
  - 예외: 나안의 간판·유리 글씨(소품)는 괜찮지만, 이름 결정(A4) 전에는 '할미 수선집' 대신 이름 없는 '옷 수선' 간판으로 만든다.
- 소리 없이 뜻이 통해야 한다. 소리를 넣는다면 숏폼판에만 넣고 사이트는 무음이다.
- 붉은 부적·태극·금박·한자 도장 남발, 무당·굿·향 연기, 어둡고 무서운 분위기, 번개·번쩍임을 쓰지 않는다.
  - **초당 3번 넘게 번쩍이는 장면 금지**(광과민성 발작 기준, WCAG 2.3.1). 등잔 일렁임은 밝기 변화를 작게 한다.
- "적중률", "정확도 ○%", "과학적으로 증명", 카운트다운, "지금 안 보면 후회" 같은 문구를 쓰지 않는다.
- **캐릭터 외형 고정**(캐릭터 바이블 D-015):
  - 복자: 검은 몸, 흰 가슴, 흰 발, 노란 눈(흰 주둥이 줄 포함, 시안 기준).
  - 할머니: 은발 쪽머리, 비녀, 동그란 안경, 저고리(동정·고름).
  - 사실적 할머니 초상(경쟁 할마카세 방식)으로 가지 않는다. 지금처럼 단순한 먹선 그림체를 유지한다.
- **기존 작품 흉내 금지**: 유명 애니메이션 스튜디오 화풍, 유명 고양이 캐릭터(장화 신은 고양이·고양이 버스 같은 것), 게임 캐릭터. 생성형 AI 영상 도구를 쓸 때도 특정 작품·작가 이름을 넣어 화풍을 따라 하지 않는다.
- 실존 인물을 닮은 얼굴, 실제 고객의 사주·이름·생년월일을 쓰지 않는다. 사주 글자가 나오면 반드시 '예시'라고 적는다.
- 동물 복지: 복자에게 사람 음식을 주지 않는다. 높은 데서 떨어지는 장면, 겁먹은 연출(털 곤두세움·하악질)을 쓰지 않는다.
- 한지 미닫이는 **띠살(세로 살 + 가로 띠 3단)** 로 그린다. 바둑판 격자(일본 쇼지)나 다다미를 쓰지 않는다. 나안은 한국 옛 가게의 **간유리 나무 미닫이**로 그린다.
- 유료 영상 도구·외주·음원 구매는 대표 승인 후 `docs/COST_REPORT.md`에 기록한다. 생성형 도구를 쓰면 상업 이용 허락(라이선스) 조건을 먼저 확인한다.
