**새로 발견한 문제 (일반 설명, 심각도)**
1. 높음(사용성·매출): 운영 기본값에서 무료 경로가 닫히는데, 화면에는 결제로 이어지는 신청 경로가 없다.
2. 중간: 생성 실패 뒤 다시 시도 횟수에 상한이 없어 풀이 1건당 AI 비용 상한이 없다. 운영 설정의 응답 길이 제한이 작아 실패가 잦을 가능성이 있음(실호출 미검증).
3. 중간: 결제는 승인됐는데 사용자가 화면을 떠나면 풀이가 없는 주문이 남을 수 있고, 자동 대사(토스 웹훅 등)가 없다.
4. 낮음: 생성 경로가 연결 주문의 결제 상태를 다시 확인하지 않는다(심층 방어 부족, 현재 생성 경로로는 미결제 풀이가 만들어지지 않음).
5. 낮음: 시간 초과 뒤에도 AI 요청 자체는 취소되지 않는다.
6. 낮음: 대기 화면이 첫 요청 유실 시 안내 없이 계속 기다리는 경우, 결제 완료 화면의 예외 처리·문구, 결제 완료 주소에 생년월일이 실림(개인정보 최소화), `VERIFYING` 상태 화면 미처리, 무료 허용 판단이 `NODE_ENV` 미설정 시 열림, 주문 준비 경로 호출 빈도 제한 없음, 서버 오류 로그에 입력값이 섞일 수 있음.
