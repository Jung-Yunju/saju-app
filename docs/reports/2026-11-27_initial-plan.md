## 4. 기존 개발 분석
### 재사용할 자산
- Next.js 16·Prisma·Neon·Google 로그인·토스 결제 골격 (타입 오류 0)
- **할머니 풀이 원칙 프롬프트**(누구에게나 맞는 말 금지, 고전의 도덕 판정 걷어내기, 겁주지 않기, 금지 주제) — 브랜드 핵심 자산
- 슬라이드형 결과 화면, 2인 풀이 상품 구상(6종)

### 문제점
1. 계산: 화면 표시용과 AI 입력용 계산이 따로 있고 42%가 서로 다름. 절기 시각 1시간 오차(중국 표준시), 윤달·서머타임·진태양시 미반영.
2. 구조: AI가 십성·합충까지 판단 → 환각 위험. 시간 초과를 출력 축소(1,000토큰)로 해결해 유료 분량 부족.
3. 결제·보안: 긴급 2건 포함 12건(세부는 별도 보고).
4. 테스트·CI 없음.
