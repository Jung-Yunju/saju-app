# 결제 전환·재방문 전략, SEO 방향, 측정 지표

> 작성: 사업기획·마케팅 담당 / 기준일 2026-11-27
> **근거 표기**: [경쟁관찰]은 `competitors.md`의 확인된 경쟁 서비스 관찰, [구조]는 우리 원가·구조에서 도출, [가설]은 일반적으로 쓰이나 이번에 외부 통계로 검증하지 못한 것(A/B로 검증 전에는 효과를 단정하지 않는다). 전환율·재구매율의 외부 수치는 이번 조사에서 확인하지 못해 싣지 않았다.

## 1. 하지 않을 것 (금지 원칙)
- "적중률 ○○%", "맞히는 AI", "100% 정확" 등 검증 불가 표현
- "지금 안 보면 불행해진다", "나쁜 운을 막으려면 결제" 식 공포·불안 자극
- 실제로 팔린 적 없는 정가를 만들어 놓고 상시 할인으로 보이게 하는 표시
- 후기·이용자 수를 지어내거나 조작
- 결과를 일부러 공포스럽게 끊어서 결제를 유도하는 미리보기
- 경쟁사 상호·문구 모방

## 2. 결제 전환 전략 5가지
1. **목차·첫 문단 미리보기 [구조/가설]**: 무료 AI 원가가 1.5원이므로 유료 풀이의 목차와 첫 문단을 사용자 본인 사주 기반으로 보여 준다. 단 풀이 내용을 불안하게 끊지 않는다. 측정: 미리보기 -> 결제 클릭률.
2. **가격 투명성 [경쟁관찰]**: 경쟁 웹 서비스에서 정가·특가가 함께 표시되는 사례가 있다(명운당). 우리는 단일 가격, 부가세 포함, 환불·열람기간을 결제 버튼 위에 표시한다. 신뢰가 곧 전환의 일부라는 가설. A/B: 문구 위치.
3. **질문형 상품명 [구조]**: 현행 6종 이름이 이미 질문형("왜 돈이 안 모일까")이라 사용자 고민과 직접 연결된다. 결과 페이지에서 사용자가 입력한 고민 카테고리에 맞는 상품을 맨 위에 노출한다. 사용자가 말하지 않은 경험을 가정하는 문구는 쓰지 않는다.
4. **묶음 제안을 구매 직전에 [가설]**: 주제 1건 결제 화면에서 "3개 묶음 34,900원(정가 합계 44,700원)" 선택지를 나란히 보여 준다. 구매 후에는 남은 주제를 "추가 구매"로 제안. A/B로 객단가 변화를 확인.
5. **첫 구매 장벽 낮추기 [경쟁관찰]**: 포스텔러가 "첫 가입 시 유료 운세 1종 무료"를 제공하고, 웹 서비스에 9,900원대 진입 상품이 많다. 우리도 진입 상품(현재 고민 9,900원) 또는 기간·횟수가 명시된 첫 구매 할인을 실험한다. 가격 인하는 전환율이 1.34배 이상이어야 이익이 같다(unit-economics §4).

## 3. 재방문 전략 5가지
6. **개인화 오늘의 운세 + 알림 [경쟁관찰]**: 점신·포스텔러·오늘운세 모두 매일 무료 운세가 핵심 재방문 장치. 무료 원가 1.5원이라 부담이 작다. 알림은 사용자가 동의한 경우만, 빈도 기본 하루 1회 이하.
7. **구매 풀이 저장·재열람 [경쟁관찰]**: 평생 열람형(정통사주, 토정비결 앱)과 15일 재열람(아시아경제 운세)이 공존. 우리의 열람 기간은 대표 결정 사항이며, 무기한이 신뢰에 유리한 가설(저장 비용은 작음). 
8. **연간 업데이트 쿠폰 [구조]**: 사주 풀이는 한 번 사면 다시 살 이유가 줄어든다. 구매자에게 매년 1월 "올해 운세" 할인 쿠폰을 제공(연 1회 재구매 동기). 
9. **1년 뒤 돌아보기 [구조]**: 기존 review 기능을 확장해 1년 후 "그때 읽은 내용을 지금 돌아보기" 알림. 목적은 본인 기록 회고이며 적중 여부를 광고에 쓰지 않는다. 사용자가 입력한 회고만 저장.
10. **공유 카드 [가설]**: 결과 공유 이미지(오행 분포·한 줄 성향)로 신규 유입. 개인 풀이 본문이나 생년월일은 카드에 넣지 않고, 공유는 사용자가 직접 누를 때만.

참고: 구독형(월 4,900원)은 재방문에 가장 직접적이나 정기결제 계약·운영 부담이 있어 2차 검토(product-proposal.md).

## 4. 범용 AI와의 차별화 메시지 (과장 없이)
- 사실 기반 문구 예: "사주 여덟 글자는 코드로 계산하고, 글은 할머니 말투로 풀어 드립니다", "한 번 구매한 풀이는 저장해 다시 볼 수 있습니다".
- 쓰지 않을 문구: "AI라서 더 정확", "과학적으로 입증". 명리 해석의 미래 예측이 과학적으로 입증된 것이 아님을 서비스 안에 고지한다("재미와 자기 이해를 위한 참고 자료").
- 근거: 무료 범용 AI 사주가 2026년 초 크게 유행했고 운세 앱 이용자가 줄었다는 기사 발췌([경쟁관찰]) — 무료 대체재와 같은 내용을 팔면 이긴다고 말하기 어렵다. 일관된 구성·저장·정확한 만세력이 우리 몫이다(가설).

## 5. SEO 키워드 방향
검색량은 이번에 확인하지 못했다(미확인). 구현 전에 네이버 검색광고 키워드도구와 구글 서치콘솔로 월 검색량을 측정한다. 방향만 제안한다.

| 묶음 | 키워드 예시 | 대응 페이지 |
|---|---|---|
| 도구형(무료) | 만세력, 무료 만세력, 사주 계산기, 내 사주 오행, 사주 팔자 보기 | 무료 만세력·오행 페이지(핵심 유입) |
| 일일 | 오늘의 운세, 띠별 운세 | 오늘의 운세 |
| 고민형(질문) | 돈이 안 모이는 이유 사주, 연애가 안 되는 사주, 직장 안 맞는 사주, 직장 상사 괴롭힘 사주, 부부 싸움 궁합 | 주제별 랜딩(상품 6종과 1:1) |
| 시즌 | 2027 신년운세, 정미년 운세, 토정비결 | 신년 상품(연말·연초 시즌) |
| 용어 설명(롱테일) | 오행 뜻, 대운이란, 용신이란, 십성 뜻 | 용어 사전 콘텐츠(연구소 감수 후) |
| 브랜드 | 할머니가 풀어 주는 사주 | 메인 |

원칙
- 용어 설명은 명리학 연구소장 감수 내용만 게시(확인하지 않은 고전 원문 인용 금지).
- 질문형 페이지는 "원인 진단 단정"이 아니라 "이런 경향이 있을 수 있다" 서술.
- 기술: Next.js 서버 렌더링으로 도구 페이지를 크롤링 가능하게(프론트엔드·백엔드와 협의), 구조화 데이터(FAQ)는 실제 콘텐츠가 있을 때만.
- 광고 집행 시 키워드 비용은 미확인. 광고 전 허용 고객획득비(unit-economics §3-3) 상한을 확인.

## 6. 측정 지표 정의
| 지표 | 정의 | 용도 |
|---|---|---|
| 방문자 (UV) | 기간 내 고유 방문자 | 유입 규모 |
| 입력 완료율 | 생년월일 입력 시작 대비 결과 화면 도달 | 무료 도구 마찰 |
| 무료 결과 조회 사용자 | 만세력 결과를 본 고유 사용자 | 퍼널 시작 |
| 미리보기 도달률 | 무료 결과 사용자 중 유료 상품 상세/미리보기를 본 비율 | 상품 관심 |
| 결제 시작률 | 미리보기 사용자 중 결제 버튼 클릭 비율 | 가격·문구 |
| 결제 완료율 | 결제 시작 대비 PAID 비율 | 결제 마찰 |
| 유료 전환율 | 무료 결과 사용자 중 기간 내 첫 결제 사용자 비율(코호트 기준 7일/30일) | 핵심 전환 |
| 객단가 (AOV) | 총 결제액 / 주문 수 | 묶음 효과 |
| 주문당 공헌이익 | unit-economics 방식 | 수익성 |
| 7일/30일 재방문율 | 첫 방문 후 N일 내 재방문 사용자 비율 | 일일 운세 효과 |
| 재구매율 | 첫 결제 후 90일/365일 내 2회 이상 결제 사용자 비율 | 연간 업데이트·묶음 효과 |
| 알림 동의율·해제율 | 알림 동의 사용자 비율, 이후 해제 비율 | 알림 품질 |
| 환불률 | 환불 건수 / 결제 건수 | 품질·기대 불일치 |
| 풀이 완독률 | 결제 후 마지막 장 도달 비율 | 콘텐츠 품질 |
| AI 생성 실패·재생성율 | 재시도 건수 / 생성 건수 | 원가·품질(COST_REPORT 20% 여유 가정 검증) |
| 고객획득비 (CAC) | 광고비 / 신규 유료 사용자 | 광고 손익 |

측정 원칙
- 개인정보(생년월일·풀이 본문)를 분석 도구에 보내지 않는다. 이벤트에는 익명 ID와 상품 코드만.
- 가격 A/B는 사용자 단위로 고정 배정하고, 최소 표본이 쌓이기 전에는 결론을 내리지 않는다(필요 표본은 통계 검토 후 설정).
- 지표 수집 구현은 프론트·백엔드 담당과 협의(이 문서는 정의만).
