## 0. 근거 표기와 한계 (먼저 읽을 것)
- **월 검색량은 이 환경에서 측정할 수 없다.** 아래 표의 "수요"는 모두 **추정**(일반적 상식에 따른 상·중·하 구분)이며 숫자가 아니다. 출시 전에 네이버 검색광고 키워드도구와 구글 서치콘솔(출시 후)로 실측해 우선순위를 다시 매긴다.
- **경쟁 페이지 관찰**은 2026-11-27에 웹 검색 도구로 몇 개 검색어를 조회한 결과다. 이 도구는 네이버·다음의 실제 검색 순위를 보여 주지 않는다(국내 검색 점유율에서 네이버 비중이 크다는 점은 일반적 인식이며 이번에 수치로 확인하지 못했다 — 추정). 따라서 "상위 유형"은 **참고 관찰**이지 순위 조사가 아니다.
- 검색어는 사람이 실제로 치는 말을 가정해 적은 것이다. 실제 자동완성·연관검색어는 출시 전 직접 확인한다.

## 3. 우선 만들 페이지 10개 (제안, 우선순위 순)
기준: 출시 때 이미 수요가 있고(추정), 우리 원고·엔진 재료가 있고, `/free`로 자연스럽게 이어지는 순서.
1. **`/unse/2027` 정미년 운세 허브** — 시즌이 가장 급하다. 원고는 `year-2026.md` 틀로 후속 작성(정미 = 丁未, 같은 규칙).
2. **`/free` 검색용 보강**(제목·메타·만세력 설명 단락·내부 링크). 별도 페이지가 아니라 도구 페이지의 SEO 마감.
3. **`/unse/2026` 병오년 허브** — 원고 완성(`content/seo/year-2026.md`). 해가 끝나가므로 "병오년 돌아보기" 성격을 더해 아카이브로 둔다.
4. **용어 `daeun`(대운)**
5. **용어 `ohaeng`(오행)** + 오행 개수 세는 법
6. **용어 `saju-palja`(사주팔자)**
7. **용어 `singang-sinyak`(신강·신약)**
8. **`/ilju` 인덱스 + 견본 3편**(갑자·을유·병오) — 60 일주 허브
9. **용어 `ilgan` + `ilju` + `sipseong`**(나머지 P0 용어)
10. **`/unse/2027/tti` 띠별 허브**(정미년 = 양띠의 해, 띠별 12 상세는 후속)

12개 용어와 일주 견본 3편, 병오년 허브는 이번에 원고 초안까지 끝났다(`content/seo/`).

## 4. 대표 결정이 필요한 검색어
| 검색어 | 문제 | 제안 |
|---|---|---|
| **삼재** | 수요는 클 것으로 추정되나, 경쟁 페이지가 "들삼재·눌삼재·날삼재"로 겁을 주는 형식이 많다(관찰: k-calc 요약). 우리 voice-guide §9가 "삼재라 큰일"을 금지. 삼재는 띠로 보는 민속적 관념이며 사주 원국 계산과 별개 | 안 만든다 또는 "삼재란 무엇인가" 정보 한 편(연구소장 감수, 공포 없이, 우리 풀이와 무관함을 밝힘). 대표 결정 |
| **토정비결** | 생년월일로 괘를 정하는 별도 점법. 우리 엔진은 만세력·명리 계산이라 **검색 의도를 충족하지 못해 이탈률이 높을 것(추정)** | 만들지 않는다. 원하면 "토정비결과 사주는 다르다" 설명 한 편 |
| **개운법·행운의 색** | voice-guide §9 개운 상품 금지 | 만들지 않는다 |
| **신살(도화·역마)** | 규칙 미확정 | 규칙 엔진 확정 후 |
| **궁합 점수** | 점수·등급 단정은 우리 원칙과 충돌 | 상품 설계 때 결정 |

## 5. 후속 작업 (담당 제안)
- 네이버 검색광고 키워드도구·구글 키워드 플래너(무료 계정)로 위 검색어 실측 → 이 표의 "수요"를 숫자로 교체. (사업기획, 출시 전. 광고 집행은 대표 승인)
- 일주 57편 나머지, 정미년 허브, 띠 12, 오행 10: 콘텐츠 작가 배정 요청(총괄실장).
- 모든 용어·학파 표현은 명리학 연구소장 감수 후 게시.
