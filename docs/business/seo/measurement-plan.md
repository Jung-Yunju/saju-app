# 검색 유입 측정 계획 (P8-02)

> 작성: 사업기획·마케팅 담당 / 2026-11-27 / 상태: **제안**. 무료 도구를 우선하고, 유료는 대표 승인 후에만 쓴다.
> 이 문서의 목표치(숫자)는 일부러 적지 않았다. 이 환경에서 업계 평균을 확인하지 못했고 우리 사이트의 기준선도 없다. **출시 후 4주치 데이터로 기준선을 만든 뒤** 목표를 정한다.

## 1. 도구 (무료 우선)
| 도구 | 쓰임 | 비용 | 비고 |
|---|---|---|---|
| 구글 서치콘솔 | 구글 검색 노출·클릭·평균 순위, 색인 상태, 사이트맵 | 무료 | 소유권 확인(메타 태그 또는 DNS). 출시 당일 등록 |
| 네이버 서치어드바이저 | 네이버 수집·검색 반응, 사이트맵·수집 요청 | 무료(검색 결과 안내 기준, 공식 문서는 이번에 열람 못 함 — 화면에서 확인) | 국내 유입 비중이 클 것으로 추정되므로 구글과 같은 날 등록. 네이버 수치는 서치콘솔에 안 잡힌다 |
| 빙 웹마스터 도구 | 빙·일부 AI 검색 노출 | 무료 | 구글 서치콘솔 가져오기로 간단 등록 가능(일반 안내, 출시 때 확인) |
| 구글 애널리틱스(GA4) 또는 자체 이벤트 기록 | 방문→/free 시작→결과 도달→공유 이동 경로 | 무료 | **개인정보 제한 아래 §3** |
| 네이버 검색광고 키워드도구·구글 키워드 플래너 | 검색량 실측(키워드 계획 보정) | 무료 계정(광고 집행은 별도) | 출시 전 1회 |
| 마이크로소프트 클래리티 등 화면 기록 | 어디서 버튼을 누르는지 | 무료 | **기본 안 씀**. 입력 화면 녹화는 개인정보 위험이 있어 쓰려면 대표 승인과 입력란 가림 설정 필요 |
- 유료 도구(순위 추적 서비스, 유료 키워드 도구, 광고)는 **대표 승인 후**. 지금은 필요 없다고 본다.

## 2. 지표 정의
| 지표 | 정의 | 출처 | 보는 단위 |
|---|---|---|---|
| 색인된 페이지 수 | 검색엔진이 수집·등록한 우리 페이지 수 ÷ 사이트맵 제출 수 | 서치콘솔·서치어드바이저 | 주간, 유형별 |
| 노출수 | 검색 결과에 우리 페이지가 보인 횟수 | 서치콘솔 | 주간, 유형·검색어 묶음별 |
| 클릭수·CTR | 클릭 ÷ 노출 | 서치콘솔 | 주간, 페이지별 |
| 평균 순위 | 해당 검색어에서의 평균 위치 | 서치콘솔 | 4주 이동 평균(널뛰기 큼) |
| 검색 유입 방문자 | 검색엔진에서 온 방문자 | GA4/자체 이벤트 | 주간 |
| **/free 전환율** | 검색 유입 방문자 중 `/free` 입력을 **시작**한 비율 | 이벤트 `free_start` + 유입 페이지 | 페이지·유형별 |
| 결과 도달률 | `/free` 시작 대비 결과 화면 도달 | 이벤트 `free_result_view` | 주간 |
| **공유율** | 결과 화면 조회 대비 공유 버튼 사용 | 이벤트 `share_click` ÷ `free_result_view` | 주간 |
| 공유 유입 | 공유 링크로 들어와 `/free`를 시작한 방문 | `?from=share` | 주간 |
| 이탈 의심 | 용어·일주 페이지 체류가 매우 짧고 /free로도 안 감 | GA4 | 월간 |
| (후속) 유료 전환 | `/free` 사용자 중 첫 결제(코호트) | `conversion-retention.md` §6 | 유료 상품 열린 뒤 |

공유율의 분모는 "결과 조회"이고 SEO 유입과 직접 연결하려면 유입 경로(`from`)를 결과 이벤트까지 들고 가야 한다(개인정보가 아닌 경로 값만).

## 3. 이벤트 설계와 개인정보 원칙 (필수)
- **생년월일·시간·성별·이름·결과 내용을 분석 도구·광고 픽셀·URL에 보내지 않는다.** 이벤트에는 "일어났다"와 경로 이름만 넣는다. (CLAUDE.md 공통규칙 13·14)
- 이벤트 이름 제안(프론트엔드 구현, 백엔드와 협의):
  - `seo_cta_click` — 속성: `page_type`(year/ilju/glossary/tti), `slug`, `position`(top/mid/end)
  - `free_start` — 속성: `from`(어느 SEO 페이지·share)
  - `free_result_view` — 속성: `from`
  - `share_click` — 속성: `channel`(카카오·링크 복사 등)
- 방문자 동의가 필요한 도구는 동의 배너 설계를 대표·프론트와 협의한다(어떤 도구를 쓸지 정한 뒤).
- 서버 로그로 직접 세는 방법도 가능: 방문자 식별을 최소화하고 일 단위 집계만 저장.

## 4. 보는 주기와 판단 규칙
| 주기 | 보는 것 | 판단 |
|---|---|---|
| 출시 당일 | 서치콘솔·서치어드바이저 등록, 사이트맵 제출, 주요 10페이지 수집 요청 | 등록 오류 없는지 |
| 주 1회 | 색인 수, 노출·클릭 상위 검색어, `/free` 전환율 | 색인이 안 되는 유형이 있는가 |
| 4주 | 기준선 만들기 | 유형별 CTR·전환 기준선 → 목표 설정 제안 |
| 8주 | 일주 상세 확대 여부 결정 | 견본 일주 페이지가 **색인되고 노출이 생겼다면** 나머지 공개, **색인 제외가 많다면** 내용 분리·보강 후 재검토 |
| 연 1회(12월) | 연도 허브 재점검 | 다음 해 허브를 11월 중순까지 공개 |

- "상위 노출 순위 N위 달성" 같은 목표는 쓰지 않는다. 우리가 통제하지 못한다.
- 지표가 나빠도 **콘텐츠에 과장을 넣어 해결하지 않는다**(적중률·공포 문구 금지 원칙).
