# 상품 구성·가격 제안서 (제안 — 최종 결정은 대표 승인)

> 작성: 사업기획·마케팅 담당 / 기준일 2026-11-27 / 근거: `competitors.md`(경쟁 가격대), `unit-economics.md`(원가·공헌이익), `docs/COST_REPORT.md`
> 모든 가격은 **부가세 포함 소비자가 제안**이다. 경쟁사 가격은 검색 발췌 기준이라 재확인 전 확정 금지.

## 0. 상품 11종 가정
총괄실장 지시서의 11종 원문을 이 작업에서 보지 못해, 현행 ReadingType 6종과 PROJECT_PLAN 메뉴 초안을 합쳐 다음 11종으로 가정했다. 목록이 다르면 배치만 바꾸면 된다.

| 구분 | 상품 | 비고 |
|---|---|---|
| 주제형 6종(현행) | 나는 어떤 사람인가 / 왜 돈이 안 모일까 / 왜 연애가 안 될까 / 왜 직장이 안 맞을까 / 이 사람은 왜 나를 괴롭힐까 / 우리는 왜 맨날 싸울까 | 질문형 제목이 검색·공유에 유리 |
| 확장 5종(가정) | 인생 총괄 / 향후 10년 / 궁합(2인) / 올해(신년) 운세 / 현재 고민 | 메뉴 초안의 할머니식 이름 사용 가능 |

주의: "이 사람은 왜 나를 괴롭힐까", "우리는 왜 맨날 싸울까"는 상대방의 생년월일 등 **제3자 개인정보**를 입력받는다. 개인정보 안내·동의 문구가 필요(백엔드·QA 확인 사항). 상대를 단정·낙인하는 서술은 피한다.

## 1. 무료 콘텐츠 배치 (세 안 공통)
무료는 "첫 방문 이유 + 신뢰 형성 + 결제 직전 미리보기" 역할이다. AI 원가는 1.5원/건 수준이라 넉넉히 줄 수 있다.

| 무료 콘텐츠 | 역할 | 비고 |
|---|---|---|
| 기본 만세력(사주 여덟 글자) | 계산 신뢰, 검색 유입 | 코드로 계산된 객관값 |
| 오행 분포 | 시각화, 공유 | 객관 집계값 |
| 성향 요약(짧게) | 흥미 유발 | 경향 서술로, 단정 금지 |
| 오늘의 운세 | **매일 재방문 장치** | 로그인 사용자는 본인 사주 기반 |
| 인생 흐름(대운 그래프, 요약) | 유료 풀이 연결 | 상세 해설은 유료 |
| 유료 미리보기 | 전환 | 풀이 첫 장 일부 + 목차 공개, 나머지는 잠금 |

미리보기 원칙: 첫 장 전체가 아니라 **목차와 첫 문단**을 공개한다. 결과를 일부러 불길하게 끊어 두려움을 자극하는 방식(공포 마케팅)은 쓰지 않는다.

## 2. 안 A — 건별형 (단순)
| 상품 | 가격 |
|---|---|
| 주제형 6종 각각 | 14,900원 (첫 구매 이벤트 9,900원 선택지는 §6) |
| 현재 고민 | 9,900원 |
| 인생 총괄 | 29,900원 |
| 향후 10년 | 19,900원 |
| 궁합(2인) | 14,900원 |
| 올해 운세 | 14,900원 |
- 묶음 할인 없음. 재방문 장치는 무료 오늘의 운세뿐.
- 장점: 구현·설명 가장 쉬움, 결제 계약이 단순(일반 결제만).
- 단점: 객단가가 낮고 구매가 1회로 끝날 위험. 여러 주제를 보고 싶은 사용자에게 가격 부담이 쌓임.
- 이 안의 공헌이익: 주제 단건 12,760원(unit-economics §2).

## 3. 안 B — 건별 + 묶음형 (권장 후보)
| 상품 | 가격 | 정가 대비 |
|---|---|---|
| 안 A의 모든 단품 | 안 A와 동일 | - |
| 주제 3개 묶음(6종 중 선택) | 34,900원 | 44,700원 대비 약 22% 할인 |
| 올패스(주제 6종 + 인생 총괄) | 69,900원 | 119,300원 대비 약 41% 할인 |
| 연애·인간관계 묶음(연애+괴롭힘+갈등) | 29,900원 | 44,700원 대비 약 33% 할인 (선택 구성안) |

- 재방문 장치: 무료 오늘의 운세 + 구매 풀이 **저장·무기한 재열람** + 연 1회 "올해 업데이트" 알림(구매자에게 신년 운세 할인 쿠폰) + 1년 뒤 "돌아보기" 알림(기존 review 기능 확장, 맞았다고 광고하는 용도가 아니라 본인 기록 회고용).
- 장점: 객단가 상승(믹스 가정 평균 약 23,900원), 구현 비용이 안 A와 거의 같다(결제는 건별 유지), 경쟁 건별 웹 서비스와 직접 비교 가능한 구조.
- 단점: 올패스를 사면 이후 재구매 여지가 줄어듦(재구매 유도는 연간 업데이트와 궁합·신년에 의존). 할인폭이 크면 단품 판매를 잠식(cannibalization) 가능 — 올패스를 "정가의 41% 할인"으로 보이게 하는 것은 정가가 실제 판매되고 있을 때만 정직하다.
- 이 안의 평균 공헌이익: 믹스 가정 약 20,200원/주문(가정 70/10/10/10).

## 4. 안 C — 구독형 (월정액 중심)
| 상품 | 가격 |
|---|---|
| 단골 구독(월) | 4,900원 (연 결제 시 월 환산 3,900원 수준 제안, 47,000원/년) |
| 포함 | 월간 운세 리포트, 개인화 오늘의 운세 상세판, 구매 풀이 무제한 재열람, 주제 풀이 20% 할인 |
| 단품 | 안 B와 동일 |

- 단점: (1) 자동결제 계약·심사가 필요할 수 있음(토스 정기결제, 미확인) (2) 해지·환불·표시 규정 준수 부담 (3) 월간 리포트가 매달 가치가 있어야 해지율이 낮아지는데, 콘텐츠 제작·검증 부담이 지속된다 (4) 초기 사용자 수가 적을 때 구독 전환 검증이 느리다.
- 공헌이익: 월 약 4,143원/명(해지율 미반영).

## 5. 비교 및 총괄실장 추천
| 기준 | A 건별 | B 건별+묶음 | C 구독 중심 |
|---|---|---|---|
| 구현 난이도 | 낮음 | 낮음~중간 (묶음·쿠폰 로직) | 높음 (정기결제, 갱신, 해지) |
| 결제 계약 변경 | 없음 | 없음 | 정기결제 계약 필요 가능 |
| 객단가 | 낮음 | 중간~높음 | 낮음(월) |
| 재방문 | 약함 | 중간 (재열람·연간 업데이트) | 강함 |
| 경쟁 비교 용이성 | 쉬움 | 쉬움 | 어려움 |
| 규제·운영 부담 | 낮음 | 낮음 | 높음 |

**추천: 안 B로 출시 -> 데이터 쌓이면 안 C의 "구독"을 2차로 검토.**
추천 이유
1. 서버·수수료 손익분기는 월 4~5건 수준이라(unit-economics §3) 지금 병목은 "구독으로 반복 매출을 만드는 것"보다 **첫 구매 전환**이다.
2. 안 B는 안 A와 구현이 거의 같고 객단가를 올릴 수 있다.
3. 구독은 자동결제 계약과 환불·해지 설계가 필요해, 대표 승인·계약이 선행되어야 한다. 전환 데이터가 생기기 전에 먼저 도입하면 위험 대비 이득이 불확실하다.

## 6. 첫 구매 장벽 낮추기 (선택안, 대표 결정)
- 첫 구매 한정 할인(예: 주제형 9,900원): 조건을 명확히 표기("첫 구매 1회, 기간 ○○까지")하고, 실제로 그 기간에 끝낼 때만 쓴다. 상시 "특가" 표시는 쓰지 않는다(명운당식 상시 특가 모방 금지).
- 무료 체험 풀이 1회: AI 원가가 약 228원이라 무료 1회 제공이 경제적으로 가능하나, 남용 방지(계정당 1회, 가입 필요)와 비용 한도가 필요하다. 효과는 미검증.

## 7. 대표 결정 항목
1. 가격 수준: 주제형 14,900원으로 인하 / 현행 19,900원 유지 / A/B 테스트 실행
2. 상품 11종의 최종 목록과 출시 순서
3. 묶음 상품(3개, 올패스) 도입 여부와 할인율
4. 구독형 도입 시점 및 정기결제 계약 진행 여부
5. 열람 기간 정책(무기한 재열람 vs 기간 제한) — 경쟁사 중 무제한과 15일 제한이 모두 존재
6. 환불 정책과 이용약관 문구(법무 확인 필요: 디지털 콘텐츠 청약철회 안내)
7. 제3자(상대방) 정보 입력 상품의 개인정보 동의 문구
