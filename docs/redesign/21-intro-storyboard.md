# 인트로 영상 — 대표 구술 콘티 (2026-11-28)

> 인트로는 **대표가 콘티를 주고 영상으로 따로 제작**한다(그래픽 담당). 개발팀은 인트로 장면을 만들지 않고 **영상 슬롯**(재생·건너뛰기·다시 보기·실패 시 바로 입력 화면)과 **마지막 장면 → 입력 화면 연결**만 맡는다. 아래는 대표 구술 요지이며, 정식 콘티가 오면 교체한다.

1. 고객이 접속하면 **어두운 방**. 복자(실제 턱시도 고양이, 코 옆 검은 점)가 들어온다. 어둠 속에서 **복자 눈이 반짝** 빛난다.
2. 복자가 할머니에게 "나와(냐옹)" 하고 묻듯 운다.
3. 할머니가 복자를 딱 보는 순간 **등불이 확 켜지며** "이놈, 왔구나."
4. 할머니가 **정면(화면 밖의 고객)을 주시**하며 말한다 — 어떤 인연으로 나한테 왔는지, 신을 부르듯이: "이놈이 왜 오늘 나한테 왔을까?" "네 인생도 변화를 맞겠구나." (예언하듯, 담담하게)
5. 뒤에는 **아주 큰 서재**. 할머니가 낡은 책 하나를 꺼내 **탁탁 먼지를 털고** 가져와 책상에 딱 펼친다.
6. 펼친 책장: **"너의 운명을 바꿔 줄 1급 비밀 · 운명비서"**, 그 아래 **"오늘의 대상자"** — 이름·생년월일 칸.
7. 그 책장이 그대로 **실제 입력 화면**으로 바뀌어 생년월일을 넣는다.

## 개발 쪽 맞춤 조건
- 영상 마지막 프레임 = 입력 화면 첫 상태(종이 색·글꼴·도장 위치·비율) — 규격은 `docs/DESIGN_SYSTEM.md` 운명비서 절.
- 영상 형식 권장: MP4(H.264) + WebM, 세로 9:16·가로 16:9 두 벌, 각 8MB 이하, 소리 없는 판 포함(자동 재생은 소리 없이만 가능), 포스터 이미지 1장.
- 건너뛰기 0초부터, 재방문 시 기본 건너뜀, 다시 보기, 영상 실패·느린 연결이면 바로 입력 화면.
