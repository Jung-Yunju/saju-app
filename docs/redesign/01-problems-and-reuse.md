## ① 현재 사이트의 문제점

### A. 대표가 지적한 것 (동의)
1. **정체성이 약하다.** 무료 결과의 중심이 "일간 하나의 물상"(예: 壬 = 바다로 가는 강, 갑 = 대들보감 나무)이다. 같은 일간이면 6,000만 명 중 1/10이 같은 첫 화면을 본다 → "나만의 것"이라는 느낌이 없다. (`content/free/day-master.json` 10종, `day-pillar.json` 60종)
2. **보고서 같다.** 화면 순서가 원국표 → 오행 개수 → 대운 띠 → 올해 기운 → 잠긴 장 목록. 정보는 정확하지만 감정이 움직이는 순간(공개·소장·공유)이 없다.
3. **촌스럽다.** 베이지·한지·먹선(시안 B)과 수선집 비유, 옛 말투가 "점집·교재" 인상. → 수선집 폐기(D-025→D-026), 말투 현대화 결정.
4. **이미지가 없다.** 복자 SVG와 글자 카드뿐. 소장·공유하고 싶은 대표 이미지가 없다.

### B. 총괄실장이 추가로 확인한 문제
5. **운영 중인 유료 풀이 구조가 원칙 위반**: `src/lib/generate-reading-v2.ts`가 AI에게 십성·합충·신살 판단을 맡긴다. 새 구조(v3: 엔진이 판단, AI는 서술)는 만들어 뒀지만 스위치 꺼짐·실제 AI 미실행.
6. **고전 원문 0건**: 규칙 표·수치는 전부 L0. "고전 기반" 표현 불가 → 신성 원형은 처음부터 "창작 상징"으로 정직하게 내세우는 편이 오히려 맞다.
7. **안전 검증기 불합격**(외부 블라인드 3차): 규칙만으로는 완곡한 위험 문장을 못 막는다 → 2층 방어 결정 필요.
8. **입력 화면**: 대표 지적(작은 입력칸·잘리는 안내) — 일부(터치 44px·글자 16px)는 밤사이 고쳤으나 시각 균형·도움말 분리는 미완.
9. **공유 카드**: 일간 별명 + 한자 한 글자 — 자랑하고 싶을 만큼의 "정체성"이 아니다.

## ⑧ 기존 vs 개선 비교
| 항목 | 기존(지금) | 개선(지시서) |
|---|---|---|
| 첫 화면 정체성 | 일간 물상 1개(10종) | **신성 원형**(12종 → 장기 108), 사주 전체 구조로 판정 |
| 결정 근거 | 일간만 | 일간·월령·오행·십성·격국·신강약·용신·조후·합충·기세 |
| 첫인상 | 원국표·숫자 | 대표 이미지 + 별칭 + 인생 한 문장 + 할머니 첫인상 |
| 흐름 | 보고서 1장 스크롤 | 공개 연출 → 5장 이야기 → 근거는 4장에 |
| 디자인 | 베이지·한지(B) | 신비·몰입(청록·미드나이트·먹·금), **원형별 테마** |
| 말투 | 옛 말투·속담 | 따뜻·재치·신랄, 현대 표준어 반말 |
| 공유 | 일간 카드 1종 | 원형 카드·스토리·카톡·배경화면·영물 비교·궁합 |
| 명리 정확성 | 엔진(검증됨) | **그대로 재사용** + 원형 근거를 4장에서 공개 |

## ⑨ 재사용할 것 / 새로 만들 것
### 그대로 재사용(검증됨)
- 만세력 엔진 `src/engine/calendar/**` (절기·한국 음력·서머타임·진태양시 — 독립 천문 라이브러리 대조)
- 규칙 엔진 `src/engine/rules/**` rules@0.4.0 (십성·지장간·합충·신강약·격국·용신·조후·기세 — 독립 오라클 대조) → **원형 엔진의 입력**
- 입력 검증·개인정보 차단(`src/lib/validate.ts`, `saju-input.ts`, `/api/free`의 DB·AI 미사용 구조)
- 콘텐츠 엔진 골격(사실표 → 장별 생성 → 검증기, v3 스위치), 개운 선택 코드(`gaeun.ts`) — 원형 서술의 "성장 과제"에 연결
- 쉬운 말 그림 말 사전, 살아온 모습 설문(D-023)
- 품질검증 테스트 2,400여 건, 비용 기록·재시도·잠금 구조

### 고쳐서 재사용
- 무료 결과 화면(`src/app/free/**`) → 5장 구조로 재구성(4장 "할미가 읽어낸 네 사주"에 기존 원국·오행·대운 표를 옮김)
- 무료 문안(`content/free/*.json`) → 원형 중심 문안으로 대체(일간·일주 문안은 4장 근거 설명에 일부 재사용)
- 공유 카드(`share-card.ts`) → 원형 카드·스토리·배경화면
- 복자 그림 → 실제 고양이 모델(D-024) + "영물을 알아보는 신비로운 고양이"
- 인트로 시안 → 공개 연출(reveal)로 흡수

### 새로 만들 것
- **신성 원형 엔진**(`src/engine/archetype/` 예정): 특징 추출 → 원형 점수 → 1·2순위 + 근거 기록, 버전 관리
- 원형 데이터 12종(이름·범주·별칭·한 문장·강점·재능·그림자·위기 능력·관계·성장 과제·근거·테마 토큰·이미지)
- 대표 이미지 12종(+변형) 제작·최적화·CDN
- 원형별 테마 시스템, 공개 연출 애니메이션
- 새 메인·입력 화면, 공유 이미지 4종(카드·스토리·카톡·배경화면)
- 2차: 영물 비교·두 영물 궁합, 오늘의 할머니 메시지, 개인 맞춤 이미지(유료)

### 정리 대상(삭제 아님 — 대표 승인 전 보존)
- 수선집·달밤 서재 문구: 달밤 서재 프롬프트 변경분은 로컬 보관(git stash) — 운영 코드에 넣지 않음
- 옛 풀이 v2 경로: v3 전환 후 대표 승인 시 정리
