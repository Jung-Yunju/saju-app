## 공통 지침 (GPT에 먼저 붙여 넣을 것)
```
너는 「운명비서(運命秘書)」라는 사주 서비스의 그림을 그린다. 모든 그림은 한 시리즈처럼 같은 화풍이어야 한다.
- 세계관: 깊은 밤, 등불 하나 켜진 비밀 서재에서 펼친 오래된 고서. 조용하고 묵직하다.
- 화풍: 오래된 동양 고서 삽화. 먹선 + 옅은 채색(담채), 종이 결이 비치는 질감. 사진·3D·애니메이션풍 금지.
- 색: 먹빛 #141310, 서재 갈색 #211C17·#382B21, 바랜 종이 #C9B898·#E2D8C5, 낡은 황동 #B9A17A, 먹선 #504335, 봉인 붉은색 #702F2B.
  원형마다 대표 색이 있지만 채도를 낮춰 이 색들 안에 녹인다. 광택 나는 금색 금지(황동처럼 바랜 빛).
- 금지: 마법진, 반짝이·별가루 효과, 과한 보라·금색, 꽃장식, 무속·부적·굿 이미지, 게임 캐릭터 같은 할머니, 파스텔, 이모지 느낌, 테두리 장식 과다.
- 그림 안에 글자·숫자·서명·로고·워터마크를 넣지 않는다(글은 화면에서 따로 얹는다).
- 사람은 얼굴을 또렷이 그리지 않는다(뒷모습·옆모습·실루엣). 보는 사람이 누구든 자기 모습으로 느끼게, 성별·나이를 드러내지 않는다.
- 결과물은 PNG, 지정한 비율 그대로.
```
