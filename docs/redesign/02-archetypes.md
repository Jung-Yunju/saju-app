# 신성 원형 12 — 판정 기준과 명리학적 근거 (제출물 ③④, ②의 명리 부분)

> 작성: 명리학 연구소장 · 2026-11-28 · 상태: **제안**(총괄실장 검토 → 대표 승인 대기). 근거 지시: [00-ceo-directive.md](00-ceo-directive.md) 3·4·13절, `docs/DECISIONS.md` D-026
> 선행 명세: [strength-structure-spec.md](../knowledge/strength-structure-spec.md)(rules@0.4.0), [rules-spec.md](../knowledge/rules-spec.md), `src/engine/rules/types.ts`(`RuleAnalysis`)
>
> **꼭 지킬 전제 네 가지**
> 1. **신성 원형은 전통 명리의 공식 분류가 아니다.** 사주 구조(엔진이 계산한 값)를 서비스가 **창작한 상징**에 대응시킨 것이다. 고객 화면에도 "명리 구조를 바탕으로 한 서비스의 상징 해석"이라고 밝힌다.
> 2. **고전 원문 인용 0건, 원문 대조(L2) 0건.** 아래 명리 서술은 모두 요지(paraphrase)다. 근거 수준: **L0** = 통설·기억(출처 미확인), **L1** = 2차 자료로 존재만 확인, **설계** = 연구소장이 이번에 정한 값·대응(고전 근거 없음). 정의는 [sources.md](../knowledge/sources.md) §0.
> 3. 명리 해석은 과학적으로 입증된 예측이 아니다. 원형은 "타고난 경향을 이야기로 풀어 보는 틀"이며, 사용자가 말하지 않은 경험을 지어내는 근거로 쓰지 않는다.
> 4. **대표 사주 24개는 모두 손계산이다.** 이번 작업 환경에 명령 실행 도구가 없어 엔진을 돌리지 못했다. 명세 사례(사례 번호 표시)의 S·T·r·조후 수치는 명세 기재값(QA 테스트 대상)이고, 새로 만든 시험용 원국 15개는 연구소장 손계산이다. **엔진 확인 전까지 "검증됨"으로 쓰지 않는다**(§9 QA 요청).

## 1. 설계 원칙

| 원칙 | 내용 |
|---|---|
| 일간 단독 금지 | 판정 조건에 **일간 글자·일간 오행을 쓰지 않는다.** 대표 사주 24개 중 같은 원형의 두 예는 모두 일간이 다르다(은빛 늑대만 한 예를 더 둠). 일간은 원형 안의 '말투·빛깔' 변형(§8)에만 쓴다 |
| 엔진 값만 사용 | 조건은 `RuleAnalysis`가 이미 내는 값과, 그 값에서 **산수로만** 얻는 파생값(§2.2)으로 쓴다. 새 명리 판단을 원형 단계에서 만들지 않는다 |
| 순서 있는 관문(캐스케이드) | 12개 관문을 정해진 순서로 검사해 **처음 통과한 원형**을 준다. 순서 = "그 구조가 원국 전체의 성격을 얼마나 강하게 지배하는가"(설계). 점수 합산 방식은 쓰지 않는다 — 왜 그 원형인지 한 줄로 설명할 수 있어야 하기 때문 |
| 빠짐없는 분할 | 관문 5~12는 신강약 판정(신약/중화/신강) × 묶음 구조로 **원국 전체를 빠짐없이 나눈다**(§3.3 증명). 그래서 모든 사주가 반드시 하나의 원형을 받는다 |
| 결정성·근거 저장 | 같은 `RuleAnalysis` + 같은 원형 규칙 버전 → 같은 결과. 통과한 조건의 값, 앞 순서 원형이 탈락한 이유, 순서와 무관하게 조건을 만족한 다른 원형(부 원형)을 모두 저장한다(§7) |
| 신강약 모형 고정 | 원형 판정은 `strengthPrimary` 옵션과 관계없이 **모형 A(weighted)** 를 쓴다(특수격 조건과 같은 방침, 명세 §2.4). 옵션을 바꿔도 원형이 흔들리지 않게 하기 위함 |
| 판정 문장 분리 | 원형 결과는 해석 문장을 담지 않는다. 강점·그림자 문장은 콘텐츠 작가가 아래 "명리 근거 요지"를 재료로 쓴다 |

## 2. 입력값

### 2.1 사용하는 엔진 출력(`RuleAnalysis`, rules@0.4.0)

| 기호 | 엔진 필드 | 쓰는 곳 |
|---|---|---|
| `A` | `strength.models.find(m => m.model === "weighted")` | 모든 관문 |
| `r`, `verdict`, `extreme`, `nearBoundary`, `total` | `A.ratio`, `A.verdict`, `A.extreme`, `A.nearBoundary`, `A.total` | 은하·5~12 관문, 안정성 표시 |
| `G` | `strength.groupTotals`(일간 제외 묶음 합) | 봉황·백호·흑여우·백록·현자·청룡·늑대 |
| `special` | `structure.candidates`의 `kind === "special"` | 은하 |
| `P` | `structure.candidates.find(c => c.role === "primary")` | 흑여우(상관격), 변형 표지 |
| `tClass`, `mClass` | `climate.tClass`, `climate.mClass` | 현무·황금빛 태양 |

| `DMF` | `qiFlow.dayMasterFlow`(`toOutput`·`toWealth`) | 청룡·늑대 |
| `circular` | `qiFlow.flowChain.circular` | 청룡·불멸의 숲 |
| `flags` | `qiFlow.clarityFlags[].flag` | 흑여우, 변형 표지 |
| 민감도 | `strength.tableSensitive`, `strength.hourSensitivity`, `structure.tableSensitive` | 안정성 표시(§3.4) |

### 2.2 파생값 (원형 모듈이 산수로 계산 — 엔진 변경 없음)

| 파생값 | 정의 | 비고 |
|---|---|---|
| `gs[g]` | `G[g] / A.total` (소수 6자리 반올림 후 비교) | 일간을 뺀 묶음 비율 |
| `maxOppose` | 관살·재성·식상 중 `G`가 가장 큰 묶음. 동점은 **관살 > 재성 > 식상** | 억부 §3.1 동점 규칙과 같음 |
| `bigyeopType` | `G.bigyeop >= G.inseong` (동점 = 비겁형) | 억부 §3.1 `ug.eokbu.strong.*` 구분과 같음 |
| `strictPairs` | X가 Y를 극하는 오행 쌍 중 `shares[X] ≥ 0.30` 이고 `shares[Y] ≥ 0.30` 이고 작은 쪽 ÷ 큰 쪽 ≥ 0.5 인 쌍 목록. 통관 오행 Z = X가 생하는 오행 | 명세 §3.3 **후보 ①**(QA 측정 8.6%). 엔진 `tonggwanMinShare` 기본값(0.25)과 **독립**으로 계산해, 통관 기본값 결정(D6-c)이 원형을 흔들지 않게 함 |

### 2.3 엔진 추가 필요 (원형 판정 자체에는 필수 아님)

| 항목 | 이유 | 우선순위 |
|---|---|---|
| **원형 모듈 신설**(예: `src/engine/archetype/**`, 규칙 버전 `archetype@0.1.0`) | 이 문서의 관문·출력 구조 구현. 파일 소유자는 총괄실장 배정 | 필수 |
| 표·시진 민감도 재계산 | 원형 모듈이 `cn-lunarjs` 표로 한 번, 시주 모름이면 12시진으로 `analyze`를 다시 돌려 원형이 바뀌는지 기록(§3.4) | 필수(원형 모듈 안에서) |

## 3. 판정 절차

### 3.1 관문 순서 (처음 통과한 원형을 준다)

| 순서 | 원형 | 관문 조건(엔진 값) | 규칙 ID |
|---|---|---|---|
| 1 | **은하** | `A.extreme !== null` 또는 특수격 후보(`kind === "special"`)가 하나 이상 | `arch.v1.01.galaxy` |
| 2 | **현무** | `tClass === "한강"` 이고 `mClass ∈ {"습강","습"}` | `arch.v1.02.hyeonmu` |
| 3 | **황금빛 태양** | `tClass === "열강"` 이고 `mClass ∈ {"조강","조"}` | `arch.v1.03.golden-sun` |
| 4 | **달의 여신** | `strictPairs.length > 0` | `arch.v1.04.moon-goddess` |
| 5 | **봉황** | `verdict ∈ {신약, 중화}` · `maxOppose = 관살` · `gs.gwansal ≥ 0.20` · `gs.inseong ≥ 0.12` | `arch.v1.05.bonghwang` |
| 6 | **백호** | `verdict = 신약` · `maxOppose = 관살` · 봉황 조건(관살 ≥ 0.20 그리고 인성 ≥ 0.12)이 **아님** | `arch.v1.06.baekho` |
| 7 | **흑여우** | `flags`에 "상관견관" / 또는 `P.name = "상관격"` 이고 `verdict ≠ 신강` / 또는 `verdict = 신약` 이고 `maxOppose = 식상` | `arch.v1.07.black-fox` |
| 8 | **백록** | `verdict = 신약` · `maxOppose = 재성` | `arch.v1.08.white-deer` |
| 9 | **지혜의 현자** | `verdict = 신강` · `G.inseong > G.bigyeop` | `arch.v1.09.sage` |
| 10 | **청룡** | (`verdict = 신강` · 비겁형 · `DMF.toOutput`) 또는 (`verdict = 중화` · `DMF.toOutput` · `DMF.toWealth` · `circular = false`) | `arch.v1.10.cheongnyong` |
| 11 | **은빛 늑대** | `verdict = 신강` · 비겁형 · `DMF.toOutput = false` | `arch.v1.11.silver-wolf` |
| 12 | **불멸의 숲** | `verdict = 중화` (앞 관문에 걸리지 않은 중화 전부) | `arch.v1.12.eternal-forest` |

- 숫자(0.30·0.5·0.20·0.12)는 전부 **설계값**이다. 0.10(식상·재성 출구)은 엔진 `dayMasterFlow` 정의값을 그대로 쓴다.
- 순서의 근거(설계, 방향만 L0):
  - 1(기세 편중)을 맨 앞에 둔다: 특수격으로 보면 용신이 억부와 정반대가 되어(명세 §2.4) 다른 구조 해석이 모두 뒤집히므로, 다른 원형으로 묶으면 설명이 모순된다.
  - 2·3(조후 극단)을 그다음에 둔다: "한난이 극심하면 조후를 먼저 본다"는 관점(궁통보감 계열 요지, L0)과 명세 §3.8 (가) 대표값 규칙(조후 극단 우선)에 맞춘다.
  - 4(양강 대치)를 묶음 구조보다 앞에 둔다: 두 세력이 맞선 원국은 "가장 큰 묶음 하나"로 성격을 말하면 나머지 절반을 지우게 된다.
  - 5~12는 신강약 × 묶음 구조. 관살 계열(5·6)을 식상(7)·재성(8)보다 앞에 두는 것은 억부 동점 규칙(관살 > 재성 > 식상)과 같은 순서다.

### 3.2 동점·경계 처리
- 비율 비교는 모두 소수 6자리 반올림 뒤에 한다(명세 §0). 경계값은 **이상(≥)** 포함.
- `maxOppose` 동점: 관살 > 재성 > 식상. 비겁형/인성형 동점: 비겁형.
- `strictPairs`가 여럿이면 X의 비율이 큰 쌍을 대표 쌍으로 두고 나머지도 모두 기록한다(동점은 오행 순서 목→화→토→금→수, 엔진 통관 동점 처리와 같음).

### 3.3 "모든 사주가 반드시 하나" — 분할 증명
1. 관문 1~4에 걸리지 않으면 `verdict`는 셋 중 하나다.
2. **신약**: `maxOppose`는 관살·재성·식상 중 하나로 반드시 정해진다 → 관살이면 5 또는 6(6은 5의 여집합), 식상이면 7, 재성이면 8.
3. **신강**: 인성형이면 9, 비겁형이면 `toOutput` 참/거짓에 따라 10 또는 11.
4. **중화**: 5·7·10에 걸리지 않으면 12.
5. 따라서 관문 12에 도달한 사주는 모두 중화다. 구현에는 그래도 안전장치(어떤 관문도 통과하지 않으면 12를 주고 `fallbackSafety: true`, QA 경보)를 둔다. 입력이 잘못된 경우(`RuleAnalysis` 누락)는 원형을 주지 않고 오류를 낸다 — 조용히 기본 원형을 주지 않는다.

### 3.4 안정성(같은 사람이 보는 방식에 따라 원형이 바뀌는가)
- **시주 모름**: 세 기둥 결과를 대표 원형으로 둔다. 원형 모듈이 12시진을 넣어 다시 판정하고, 원형이 둘 이상 나오면 `hourSensitive: true`와 시진별 원형 목록을 남긴다. 콘텐츠는 "태어난 시간을 알면 다른 모습이 보일 수 있단다" 수준으로만 쓴다(사례 6 참고).
- **지장간 표**: `cn-lunarjs` 표로 다시 판정해 다르면 `tableSensitive: true`. 근거 화면에만 둔다.
- **경계 근접**: `A.nearBoundary`가 참이고 신강약 판정을 바꾸면 원형이 바뀌는 경우 `nearBoundary: true`. QA 측정상 경계 근접이 원국의 32.9%라 고객 화면 판정 옆에는 붙이지 않는다(명세 §1.9의 30% 원칙과 같은 이유).
- 이 세 표지는 원형을 바꾸지 않는다(대표 원형은 항상 선택한 옵션의 결과). 숨기지 않고 기록할 뿐이다.

| 12 | 불멸의 숲 | 자연 | 중화·주류(고른 순환) — 최종 분할 | 깊은 녹·청록·금빛 햇살 | 사계 공존 · 새순과 단풍이 함께 있는 고목 숲 | 8~12% |

- 범주 구성: 신수 4(현무·봉황·백호·청룡) · 영물 3(흑여우·백록·은빛 늑대) · 신성한 인간 2(달의 여신·지혜의 현자) · 자연 2(황금빛 태양·불멸의 숲) · 천체 1(은하).
- **추정 비율은 측정값이 아니다.** QA 분포 측정(신강 28.1%·중화 23.8%·신약 48.1%, extreme 4.9%, 통관 후보 ① 8.6%)을 바탕으로 연구소장이 어림한 값이며, 조후 극단 비율은 측정된 적이 없어 가장 불확실하다. §6의 측정 후 보정한다.
- 이번 12개에서 뺀 후보(기린·주작·백여우·신비로운 고양이·별의 예언자·태양의 수호자·깊은 바다·영원의 산맥·달·별·태양)는 108 확장용으로 남긴다(§8). **신비로운 고양이는 안내자 복자(D-024)와 겹쳐 원형에서 뺐다**(대표 결정 2).

## 5. 원형별 명세

> 각 원형의 "명리 근거 요지"는 콘텐츠 작가의 문장 재료다. **결혼·출산·질병·사망·재산을 확정하는 문장, 성별에 따라 뜻을 바꾸는 문장, "귀한/천한 사주" 같은 판정은 쓰지 않는다.** 고전의 성별·도덕 판정은 원문 기록 쪽(지식 항목 `removed_in_modern`)에만 남기고 여기서는 걷어 냈다.
> 대표 사주 표기: 연/월/일/시. S·T는 u 단위(천간 1.0 = 30u, 명세 §0.1), 지장간 표 `kr-monthly-30`, 기본 옵션. "손계산"은 연구소장이 명세 규칙으로 계산한 값.

### 5.1 은하 (銀河) — 천체 · 순서 1
- **구조**: 일간이 극히 약하거나(r ≤ 0.20) 극히 강하거나(r ≥ 0.80), 엔진이 특수격 후보(종격·종왕·종강·화격·일행득기)를 낸 원국. 균형을 맞추기보다 **하나의 큰 기세를 따른다**고 보는 관점이 있는 구조(종격 개념 L0, 적천수 계열에 종상·화상 조항이 있다는 2차 자료 L1).
- **테마**: 남보라·별빛 은 / 계절 없음 / 은하수가 그대로 비치는 고요한 호수. 반영 속 영물(제안): 은빛 미르(용).
- **변형 표지**: `종살 후보`·`종재 후보`·`종아 후보`·`종세 후보`·`종왕 후보`·`종강 후보`·`화○격 후보`·`일행득기 후보`·`극신약(종격 조건 미충족)`·`극신강(후보 없음)`.
- **대표 사주**
  | 예 | 원국 | 핵심 값 | 판정 |
  |---|---|---|---|
  | 은하-1 (명세 사례 8) | 庚申 / 戊子 / 丙申 / 壬辰 · 일간 丙 | S 39 / T 315, r 0.123810, extreme weak, 종살격 후보(low) | 관문 1 통과 → 은하 · 표지 `종살 후보` |
  | 은하-2 (명세 사례 9) | 戊午 / 己未 / 戊戌 / 丁巳 · 일간 戊 | S 285.5, r 0.906349, extreme strong, 종왕격 후보(low). 조후 T 4.0·M −3.5(태양 조건도 충족) | 관문 1 → 은하 · 부 원형 황금빛 태양 |
  - 참고: 명세 사례 10(庚辰/己丑/甲戌/戊辰, r 0.257)은 extreme이 아니지만 화토격 후보가 있어 은하.
- **명리 근거 요지(작가용)**
  - 강점 ① 한 방향으로 몰입하는 순도 높은 집중력(한 기운이 원국을 거의 차지함) ② 큰 흐름·분위기를 읽고 그에 실리는 감각(종 = 따름의 관점, L0) ③ 섞이지 않은 뚜렷한 개성(`qiFlow.concentration`이 높음).
  - 그림자: 반대 기운을 만나면 흔들림이 크다고 보는 관점(종격은 거스르는 기운을 꺼린다는 요지, L0). 보는 방식(억부 vs 특수격)에 따라 해석이 정반대가 되므로 스스로도 "나는 강한가 약한가"가 헷갈리기 쉬운 구조.
  - 성장 과제: 흐름에 실릴 때와 버틸 때를 가르는 것, 원국에 거의 없는 기운(`qiFlow.missing`)과 이어 주는 사람·습관.
  - 주의: 특수격은 `confidence: low`다. 고객 문장에 "종격 사주다"라고 단정하지 않는다(명세 §9.2-2). 근거 화면에서만 "이렇게 보는 관점도 있다"로 쓴다.

### 5.2 현무 (玄武) — 신수 · 순서 2
- **구조**: 겨울 냉기가 극심하고(T ≤ −2) 물기가 많은(M ≥ 1) 원국. 조후 관점에서 **따뜻하게 하고 말리는 기운이 급하다**고 보는 구조(조후 우선 관점 L0, 지수는 climate-v1 설계 — 궁통보감 표 아님).
- **테마**: 먹빛 검정·심청·서리 은 / 한겨울 / 얼어붙은 깊은 호수, 눈 덮인 북쪽 바위, 낮게 깔린 안개. 반영 속 영물: 거북과 뱀(현무 자신).
- **변형 표지**: 부 원형(관문 5~12 중 순서 무시하고 충족한 첫 원형) — 예: `현무·봉황결`, `현무·늑대결`.
- **대표 사주**
  | 예 | 원국 | 핵심 값 | 판정 |
  |---|---|---|---|
  | 현무-1 (명세 사례 12) | 癸亥 / 癸亥 / 壬子 / 辛丑 · 일간 壬 | r 0.765079 신강(extreme 아님), T −5.0 한강, M 4.5 습강, 윤하격 후보 아님 | 관문 2 → 현무 · 부 원형 은빛 늑대(식상 목 0.089 < 0.10) |
  | 현무-2 (손계산) | 戊辰 / 甲子 / 丙寅 / 己亥 · 일간 丙 | S 110.5 → r 0.350794 신약. T = −2 + 0.5×(0−1−1) + 0.5×(1−0) = **−2.5 한강**, M = 2 + 0.5×(1+0+1) + 0.5×(0−1) = **2.5 습강**. 특수격 없음(丙은 甲·己와 합 없음) | 관문 2 → 현무 · 부 원형 봉황(관살 수 109 = 0.346, 인성 목 70 = 0.222) |
- **명리 근거 요지**
  - 강점 ① 깊이 생각하고 오래 참는 힘(겨울 = 갈무리[藏]의 계절, 수 = 지혜[智] 배속 — L0) ② 위기에서 흔들리지 않는 냉정함 ③ 모아 두고 아껴 쓰는 저장력.
  - 그림자: 마음이 늦게 풀리고 시동이 늦게 걸림, 걱정이 고여 있는 편(한습 = 움직임이 굳는 기후라는 조후 요지, L0).
  - 성장 과제: 온기(화)를 들이는 생활 — 햇빛·몸을 움직이는 일·사람과 웃는 시간·표현. 문구는 "계절 기운으로 보면 따뜻한 기운이 반가운 편" 수준(명세 §3.2).

### 5.3 황금빛 태양 — 자연 · 순서 3
- **구조**: 여름 열기가 극심하고(T ≥ 2) 마른(M ≤ −1) 원국. 식히고 적시는 기운이 급하다고 보는 구조(L0 방향, climate-v1 설계).
- **테마**: 황금·주홍·따뜻한 아이보리 / 한여름 정오 / 아지랑이 피는 금빛 들판, 햇빛이 쏟아지는 연꽃 연못. 반영 속 영물(제안): 삼족오.
- **대표 사주**
  | 예 | 원국 | 핵심 값 | 판정 |
  |---|---|---|---|
  | 태양-1 (손계산) | 甲午 / 庚午 / 壬戌 / 丙午 · 일간 壬 | S 73.5 → r 0.233333 신약(extreme 아님, 0.20과 0.033 차이). T = 2 + 0.5×(2+0+2) + 0 = **4.0 열강**, M = −2 + 0.5×(−2−1−2) + 0 = **−4.5 조강**. 격: 午월 여기 丙 시간 투출 → 편재격(low, 정기 고정이면 정재격) | 관문 3 → 태양 · 부 원형 백록(재성 화 139.5 최대) |
  | 태양-2 (손계산) | 丁巳 / 丁未 / 庚戌 / 甲申 · 일간 庚 | S 161.5 → r 0.512698 중화. T = 2 + 0.5×(1+0+1) + 0.5×2 = **4.0 열강**, M = −1 + 0.5×(−1−1+0) − 0.5×2 = **−3.0 조강**. 격: 未월 여기 丁 투출 → 정관격(low) | 관문 3 → 태양 · 부 원형 봉황(관살 화 107.5 = 0.341, 인성 토 95 = 0.302) |
  - 두 예 모두 일간은 물·쇠(壬·庚)다. 불 일간이 아니어도 원국 전체가 뜨겁고 마르면 이 원형이다.
- **명리 근거 요지**
  - 강점 ① 빛나는 존재감과 열정(화 = 밝음·드러남 배속, L0) ② 빠른 추진력 ③ 주변을 데우는 낙관과 표현력.
  - 그림자: 과열·소진, 성급함, 마른 땅처럼 감정의 여백이 부족해지는 때.
  - 성장 과제: 수(쉼·밤·물·성찰)를 들이는 리듬. "식혀 주는 기운이 반가운 편".

### 5.4 달의 여신 — 신성한 인간 · 순서 4
- **구조**: 서로 극하는 두 오행이 각각 원국의 30% 이상, 크기도 비슷하게(작은 쪽이 큰 쪽의 절반 이상) 맞선 **양강 대치**. 두 힘을 이어 주는 오행(통관)이 반갑다고 보는 구조(통관 개념 L0, 기준은 명세 §3.3 후보 ① 설계값).
- **테마**: 진주 은백·미드나이트 블루 / 춘분·추분(낮과 밤이 비슷한 때) / 해와 달이 함께 뜬 하늘 아래 달빛 연못, 두 물줄기가 만나는 곳. 반영 속 영물(제안): 옥토끼.
- **변형 표지**: 대치 쌍과 통관 오행 — `금↔목·수로 이음`, `수↔화·목으로 이음`, `목↔토·화로 이음`, `화↔금·토로 이음`, `토↔수·금으로 이음`.
- **대표 사주**
  | 예 | 원국 | 핵심 값 | 판정 |
  |---|---|---|---|
  | 달-1 (명세 사례 4) | 丙寅 / 庚子 / 壬午 / 丁未 · 일간 壬 | r 0.476190 중화. 수 120u(0.381) vs 화 107.5u(0.341), 비 0.896. 丁壬합은 있으나 庚 투출로 화격 H3 불성립 | 관문 4 → 달의 여신 · `수↔화·목으로 이음` |
  | 달-2 (명세 사례 5) | 戊寅 / 辛酉 / 甲寅 / 乙亥 · 일간 甲 | r 0.390476 신약. 금 120u(0.381) vs 목 107u(0.340), 비 0.892 | 관문 4 → 달의 여신 · `금↔목·수로 이음` · 부 원형 백호 |
  - QA 측정과 일치 확인: 명세 사례 중 후보 ①이 성립하는 것은 사례 4·5뿐(TEST_REPORT).
- **명리 근거 요지**
  - 강점 ① 맞선 두 쪽을 이어 주는 중재력(통관 = 사이를 잇는 기운, L0) ② 양쪽을 다 이해하는 이중 시야와 공감 ③ 긴장 속에서 균형점을 찾는 감각.
  - 그림자: 안에서 두 목소리가 다투는 듯한 망설임, 양쪽 눈치를 보다 지침.
  - 성장 과제: 통관 오행을 생활로 옮긴 '다리'(예: 수 = 배움·쉼, 목 = 성장·기획, 화 = 표현, 토 = 신뢰·중심, 금 = 정리·결단 — 오행 통용 상징 L0)를 기르고, 둘 중 하나를 버리지 않고 순서를 정하는 것.

### 5.5 봉황 (鳳凰) — 신수 · 순서 5
- **구조**: 관살(나를 다스리는 힘)이 가장 큰 빼는 힘이지만 인성이 그것을 받아 일간을 살리는 원국(신약·중화). 압박이 배움·자격·신뢰로 바뀌는 **관인상생·살인상생** 흐름(L0; 명세 상신 표에서 칠살격의 상신 = 인성[화살], 정관격의 상신 = 인성 — L0).
- **테마**: 붉은빛·금(대표 제시) / 늦봄~초여름 / 노을 진 오동나무 숲 위 구름. 반영 속 영물: 봉황 자신.

  - 성장 과제: 관(마감·규칙)으로 다듬고, 갈래를 줄여 한 줄기를 끝까지 키우기.

### 5.11 은빛 늑대 — 영물 · 순서 11
- **구조**: 신강·비겁형이고 식상(출구)이 원국의 10% 미만인 원국. 힘은 넘치는데 흘려보낼 길이 좁은 **비겁 군집** 구조(L0). 억부로는 관살로 다스리거나 식상으로 흘리는 것이 반갑다(명세 §3.1 `ug.eokbu.strong.bigyeop`).
- **테마**: 은회색·청회색·눈빛 / 초겨울 / 첫눈 내린 달밤의 고원 능선. 반영 속 영물: 은빛 늑대 자신.
- **변형 표지**: `건록결`/`양인결`/`월겁결` · `쟁재`(재성 ≥ 0.15 또는 비겁쟁재 표지) · `관살 제어`(관살 투출).
- **대표 사주**
  | 예 | 원국 | 핵심 값 | 판정 |
  |---|---|---|---|
  | 늑대-1 (손계산) | 丁卯 / 己酉 / 庚辰 / 甲申 · 일간 庚 | S 200 → r 0.634921 신강. 비겁 106 ≥ 인성 64, 식상 수 11.5u = 0.037. 酉 = 庚 양인 → 양인격, 丁(정관) 투출. 조후 T 1.0·M 0 | 관문 11 → 늑대 · `양인결`·`관살 제어` |
  | 늑대-2 (손계산) | 戊寅 / 辛酉 / 辛卯 / 甲午 · 일간 辛 | S 196 → r 0.622222 신강. 비겁 120 ≥ 인성 46, 식상 0(수 없음). 酉 = 辛 록 → 건록격, 상신 재성 甲 투출. 재성 91 = 0.289. 조후 T 0.5·M −1.0 | 관문 11 → 늑대 · `건록결`·`쟁재` |
  - 시주 모름 사례(명세 사례 6, 丙寅/丁酉/庚辰/모름): 세 기둥으로는 r 0.603922 신강·식상 0.018 → 늑대. 그러나 壬午시를 넣으면 명세 사례 3(중화 → 봉황)이 된다 → `hourSensitive: true`. 시각 모름 사용자에게 원형이 시진에 따라 바뀔 수 있음을 보여 주는 예.
- **명리 근거 요지**
  - 강점 ① 스스로 서는 자립심과 추진력(비견 = 스스로 서려는 힘, L0) ② 동료를 지키는 의리 ③ 끝까지 가는 근성(겁재 = 승부욕, L0).
  - 그림자: 고집과 경쟁심, 몫을 두고 다툼(비겁쟁재 요지, L0), 속마음을 말로 꺼내는 출구가 좁음(식상 약).
  - 성장 과제: 표현의 출구(말·작품·가르침 = 식상) 만들기, 규칙(관)을 '나를 묶는 것'이 아니라 '무리를 지키는 것'으로 받아들이기.
  - 걷어 낸 옛 판정(원문 기록 쪽에만): 비겁이 많으면 배우자를 극한다는 판정.

### 5.12 불멸의 숲 — 자연 · 순서 12 (최종 분할)
- **구조**: 중화(0.45 ≤ r < 0.55)이면서 앞의 관인상생·상관·식신생재 구조에 걸리지 않은 원국. 한쪽으로 크게 기울지 않은 구조이고, circular이면 다섯 기운이 상생으로 이어 도는 **주류**(L0)에 가깝다.
- **테마**: 깊은 녹·청록·금빛 햇살 조각 / 사계 공존 / 새순과 단풍이 한 숲에 함께 있는 고목 숲과 샘. 반영 속 영물(제안): 백록 새끼 또는 숲의 정령(디자인 실장 협의).
- **변형 표지**: `순환결`(circular) · `고요결`(그 밖) · 주 격 이름 · `관살과 비겁의 균형` 등 두 묶음 맞섬(양강 대치 기준 미달).
- **대표 사주**
  | 예 | 원국 | 핵심 값 | 판정 |
  |---|---|---|---|
  | 숲-1 (손계산) | 丁酉 / 甲辰 / 甲寅 / 壬申 · 일간 甲 | S 157 → r 0.498413 중화. 오행 목 0.352·화 0.129·토 0.227·금 0.146·수 0.146 → 모두 ≥ 0.10, circular. 관살 0.146 < 0.20 → 봉황 아님. 상관(丁)은 있으나 정관 투출 없음. 辰월 → 편재격. 조후 T 0·M 1.0 | 관문 12 → 숲 · `순환결` |
  | 숲-2 (손계산) | 庚辰 / 甲申 / 乙卯 / 戊寅 · 일간 乙 | S 154 → r 0.488889 중화. 묶음: 비겁 100 · 인성 24(0.076) · 식상 7 · 재성 76 · 관살 78(0.248). 인성 부족으로 봉황 아님, 식상 0.022로 청룡 아님. 申월 정기 庚 연간 투출 → 정관격. 조후 T 0.5·M 0.5 | 관문 12 → 숲 · `고요결`·`관살과 비겁의 균형` |
- **명리 근거 요지**
  - 강점 ① 균형 감각(중화) ② 흔들려도 제자리로 돌아오는 회복력(주류 = 막힘없이 돎, L0) ③ 여러 자리에 맞추는 적응력.
  - 그림자: 뚜렷한 한 방향이 없어 보여 개성이 흐려 보임, 결정을 미룸, 무난함에 안주.
  - 성장 과제: 스스로 고른 한 가지에 깊이를 더하기.
  - 쓰지 말 것: "중화라서 좋은 사주", "평범한 사주". 균형은 좋고 나쁨이 아니라 성질이다.

## 6. 목표 분포와 보정 규칙

### 6.1 목표
- 원형마다 **4~15%**(대표 예시 범위)를 목표로 한다. 다만 은하처럼 구조 자체가 드문 원형은 3~7%를 허용한다 — 드문 구조를 억지로 늘리면 판정이 틀려진다.
- 측정 표본: QA 기존 표본(1900~2100 양력 무작위, 시드 20261128, 시각 앎 10,000 + 모름 2,000)을 그대로 쓴다. 시각 앎·모름 집단을 따로 보고한다(시각 모름은 세 기둥이라 조후 극단이 덜 나온다 — 정규화하지 않는 명세 §4.2 때문).

### 6.2 보정 손잡이(설계값과 허용 범위)
| 원형 | 손잡이 | 기본 | 허용 범위 | 비율이 높으면 / 낮으면 |
|---|---|---|---|---|
| 현무·태양 | 습도·건조 조건 | `습 이상`·`조 이상` | `습강`·`조강`만 ~ 지금 | 높으면 `습강/조강`만, 그래도 높으면 T 기준 ±2.5 |
| 달의 여신 | 양강 대치 기준 | 0.30 / 0.5 | 0.28/0.6 ~ 0.33/0.5 | 명세 §3.3 후보 ①·② 측정값 참고(8.6% / 15.3%) |
| 봉황 ↔ 백호 | 인성 하한 | 0.12 | 0.10 ~ 0.15 | 봉황이 많으면 올림(백호로 이동) |
| 봉황 | 관살 하한 | 0.20 | 0.18 ~ 0.25 | 많으면 올림 |
| 흑여우 | 세 갈래 중 상관격 갈래 | 켬 | 켬/끔 | 많으면 상관격 갈래를 끔 |

| 숲 | 없음(나머지) | — | — | 15%를 넘으면 청룡 중화 갈래의 `circular=false` 조건 재검토 |

- **금지**: 해시·무작위로 원형을 나누는 것, 분포를 맞추려고 구조와 무관한 조건(일간 글자 등)을 끼우는 것. 손잡이로도 15%를 넘는 원형은 **억지로 줄이지 않고** 108 확장에서 두 원형으로 나누는 안을 낸다.
- 보정 결과는 규칙 버전(`archetype@0.1.x`)을 올리고 이 문서와 `docs/DECISIONS.md`에 남긴다. 이미 받은 원형이 바뀌는 고객이 생기므로 버전별 결과를 저장해 두는 정책이 필요하다(대표 결정 4).

## 8. 108 확장 원칙 (요약 1쪽)

1. **층 구조**: 1층 = 이번 12 원형(주 구조). 2층 = 원형 안의 **변형**. 108은 2층까지 합친 **상한 목표**이며 원형마다 변형 수가 달라도 된다. 12 × 9로 기계적으로 채우지 않는다.
2. **변형을 나누는 축(엔진 값만)**
   - ① 부 원형(`secondary`) — 현무·황금빛 태양·달의 여신처럼 앞 순서 원형은 아래에 깔린 구조가 사람마다 다르다(예: 현무·봉황결, 현무·늑대결).
   - ② 구조 표지 — 주 격 이름, `clarityFlags`, 통관 쌍, 특수격 종류(은하: 종살·종재·종아·종세·종왕·종강·화격·일행).
   - ③ 기운의 빛깔 — 일간 오행·음양은 **판정이 아니라 말투·색조 변형**에만 쓴다(예: 같은 백호라도 갑목 백호는 "자라나며 단련되는 범"). 일간만으로 원형을 바꾸지 않는다는 원칙은 2층에서도 지킨다.
   - ④ 계절 배경 — 실제 월지 계절(봄·여름·가을·겨울)로 대표 이미지 배경만 바꾼다(이미지 비용 결정과 연결, 대표 결정 5).
3. **변형 성립 기준(설계)**: ⓐ 엔진 값으로 정의되는 실제 구조 차이가 있을 것 ⓑ 측정 표본에서 0.5% 이상일 것 ⓒ 강점·그림자 중 적어도 하나가 상위 원형과 **다른 명리 근거**를 가질 것(이름·색만 다른 변형 금지) ⓓ 대표 사주 2개를 엔진으로 확인할 것.
4. **새 상징 후보(예비)**: 기린(중앙·토의 인수 — 중화 변형), 주작(남방·화 — 염조 변형 또는 상관 화려형), 백여우, 별의 예언자(편인 직관형), 태양의 수호자, 깊은 바다, 영원의 산맥(종왕·종강 변형), 달·별·태양(천체). 신비로운 고양이는 복자와 겹치므로 대표 결정 전까지 쓰지 않는다.
5. **한 원형이 15%를 넘을 때**: 손잡이(§6.2)로도 안 되면 변형 중 가장 큰 덩어리를 1층 원형으로 올리는 안을 낸다(예: 봉황 → 봉황/기린 분리). 이때 규칙 버전을 올리고 기존 고객 결과 보존 정책을 따른다.
6. **절차**: QA 분포 측정 → 연구소장 변형 정의(이 문서 갱신) → 작가 문안 → 디자인 시안 → QA 일관성 검증(같은 사주 = 같은 변형, 변형 근거가 원국에 있는지) → 대표 승인.
7. **예시 규모(가늠용)**: 은하 8 · 달의 여신 5 · 현무 6 · 황금빛 태양 6 · 나머지 8개 원형 각 6~9 → 약 90~110. 측정 전 숫자이며 약속이 아니다.

## 9. 학파 충돌·한계와 QA 요청

### 9.1 이 설계가 기대는 학파 선택(바뀌면 원형도 바뀜)
| 지점 | 이 문서의 선택 | 다른 선택 시 영향 |
|---|---|---|
| 신강약 | 모형 A 고정 | 모형 B로 보면 사례 3·5·11처럼 판정이 갈림 → 원형이 바뀔 수 있음(`stability`에 기록하지 않음 — 모형 비교는 근거 화면 몫) |
| 조후 | climate-v1(설계 지수), 궁통보감 표 미적용 | 표가 L2로 채워지면 현무·태양 기준을 다시 정해야 함 |
| 특수격 | 후보만(low)으로도 은하 | 특수격을 끄면(`specialStructures: "off"`) 화격 후보만 있던 원국이 다른 원형으로 감. **옵션과 원형을 묶을지 대표 결정 3** |
| 통관 | 후보 ① 기준을 원형 모듈이 독립 계산 | 엔진 통관 기본값(D6-c)과 숫자가 달라질 수 있음 — 의도된 분리 |
| 합화·충 | 반영 안 함(엔진 1차 방침) | 합화를 반영하는 학파에서는 묶음 비율이 달라짐 |

### 9.2 한계
- 경계 근접(32.9%)과 지장간 표 차이(18.1%) 때문에, 원형이 "보는 방식"에 따라 바뀌는 사람이 적지 않을 것으로 예상한다. 숨기지 않고 `stability`에 남기되 고객 첫 화면에는 대표 원형 하나만 보인다.
- 원형과 상징의 대응은 창작이다. "백호라서 성격이 이렇다"가 아니라 "이 구조를 백호라는 그림으로 풀었다"로 서술한다.

### 9.3 QA 요청
1. 대표 사주 24개(명세 사례 9 + 손계산 15)를 엔진에 넣어 S·T·r·묶음 합·조후·표지·격이 이 문서와 같은지, 원형 관문을 독립 구현으로 적용해 같은 원형이 나오는지 확인.
2. §6.1 표본으로 원형별 비율, `tableSensitive`·`hourSensitive` 비율, 부 원형 분포 측정.
3. §3.3 분할 증명의 실측 확인: `fallbackSafety`가 0건이어야 함.

## 10. 대표 결정이 필요한 사항
1. **12 원형 구성과 이름 승인** — 특히 주작·기린을 이번에 넣지 않고 황금빛 태양·불멸의 숲을 넣은 것(범주 고루 섞기 목적).
2. **신비로운 고양이 제외** — 안내자 복자(D-024)와 겹쳐 원형에서 뺌. 넣기를 원하면 복자와 구분되는 이름이 필요.
3. **특수격 후보만으로 은하를 줄지** — 추천: 준다(극단 구조 자체는 엔진 수치로 확실하고, 이름은 상징이라 위험이 작다). 단 근거 화면에서 "종격이다" 단정 금지.
4. **규칙 보정으로 원형이 바뀔 때 기존 고객 결과를 유지할지** — 추천: 처음 받은 원형과 규칙 버전을 저장해 그대로 보여 주고, 다시 풀기를 고를 때만 새 버전 적용.
5. **'내면의 영물'을 어떻게 정할지** — (가) 원형마다 짝 영물 하나 고정(이 문서 "반영 속 영물" 칸, 이미지 12세트) / (나) 부 원형에서 영물을 가져와 조합(개인화는 크지만 이미지 수 증가). 추천: 1차 (가), 108 확장 때 (나) 검토.
6. **대표 이미지 계절 배경** — 원형 고정 계절(12장) / 실제 태어난 계절로 4종 변형(48장). 비용은 디자인·백엔드 산정 후.
