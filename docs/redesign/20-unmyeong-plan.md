# 「운명비서(運命秘書)」 전면 수정 — 분석·수정 계획·작업 카드 (총괄실장)

> 대표 지시서 「할머니가 풀어 주는 사주 – 운명비서」(2026-11-28, D-027)를 구현한다. 바로 앞 지시(D-026 신성 원형)는 **흡수**: 원형 엔진은 무료 2장 「너의 신성과 영물」로 들어간다. 색·세계관은 이번 지시가 우선.
> 원칙: 기존 계산 엔진은 건드리지 않는다(그래픽 계층과 분리). 기존 화면은 지우지 않고 새 경로로 만든 뒤 승인 시 전환.

## 0. 먼저 알려 드릴 것
1. **"첨부한 인트로 콘티 이미지"가 이번 메시지에 없다.** 콘티 글(SCENE 01~05)을 기준으로 진행하고, 이미지가 오면 색 토큰을 추출해 맞춘다.
2. **색 겹침 위험**: 제시 색(먹빛 갈색 + 황동)은 경쟁 서비스 할마카세(어두운 갈색 + 금)와 계열이 같다. 구별은 ① 복자(실제 고양이) ② 운명비서 고서 세계관 ③ 광택 없는 황동·붉은 봉인 ④ 근거 공개로 한다. 대표 판단 필요 시 알림.
3. **5대 고전**: 지금까지 원문 대조 0건(감사 보고). "고전 관점을 활용하는 구조"는 유지하되 **고전 인용·"○○에 이르기를"은 쓰지 않는다**(지시서 10절과 같은 원칙). 원문 확보는 사이트 접속 허용(대표 결정 D6) 후.
4. 그래픽(인트로 영상·할머니·복자·서재·표지·종이·영물·삽화)은 **GPT 그래픽 담당**이 만든다(11절). 우리는 **임시 리소스 + 교체 가능한 자산 구조**를 만든다. 임시 그림을 최종으로 보지 않는다.

## 2. 구조 (계약 — 직원들은 이 이름으로 맞춰 만든다)
- **새 경로** `/unmyeong` (인트로 → 입력(고서 첫 장) → 로딩 → 무료 결과). 기존 `/`, `/free`, `/input`은 **보존**(대표 승인 시 홈 전환).
- **디자인 토큰** `src/styles/unmyeong.css` — `.um-root` 범위의 CSS 변수:
  `--um-bg #141310`, `--um-study #211C17`, `--um-wood #382B21`, `--um-paper #C9B898`, `--um-text #E2D8C5`, `--um-brass #B9A17A`, `--um-line #504335`, `--um-seal #702F2B`, 그리고 `--um-text-ink`(종이 위 글자), `--um-space-1..8`, `--um-font-title`(명조), `--um-font-body`(본문), `--um-fs-xs..2xl`, `--um-radius-s/m`, `--um-shadow-page`, `--um-shadow-lamp`, `--um-btn-*`. 글꼴은 `next/font`(방문자 IP를 Google에 보내지 않음).
- **자산 관리** `src/lib/unmyeong/assets.ts` — 형식 있는 목록(manifest): `intro.video`(src·poster·길이, 없으면 null) · `intro.fallback`("scene" = CSS/SVG 대체 장면) · `grandma` · `bokja` · `study` · `bookCover` · `paperTexture` · `archetypes[id].{human, beast, alt}` · `illustrations[chapterId]`. 파일은 `public/unmyeong/placeholder/**`(임시) → `public/unmyeong/final/**`(GPT 그래픽 담당 납품) — **목록 한 줄만 바꾸면 교체**.
- **유료 5권 설정** `content/unmyeong/volumes.json` + `src/lib/unmyeong/volumes.ts` — 권 번호·제목·부제·포함 장(v3 장 id)·상품 코드·노출 여부. 가격·결제 연결은 **바꾸지 않는다**(결제 변경은 대표 확인).
- **무료 결과 API** `POST /api/unmyeong/free` — DB·AI·로그인 없음(현행 `/api/free`와 같은 보안 조건). 응답: 원국 표시값, 원형 결과(id·근거·민감도), 5장 문안(원형 × 구조 수식어, `content/unmyeong/free-copy.json`), "할미는 어떻게 알았을까?" 근거. **이름은 서버로 보내지 않고 화면에서만 끼운다.**
- **원형 엔진** `src/engine/archetype/**` — 연구소장 12안(`02-archetypes.md`) + 실험 도구 실측 결과로 구현, `archetype@0.1.0`, 결정론적·근거 기록. 공개 API 추가는 총괄실장 승인(D-027 범위).

## 4. 검수 기준 (지시서 13절 그대로 — 품질검증이 항목별로 판정)
색 일관성 · 고서→입력 자연 연결 · 할머니·복자 외형 일관 · 무료 간결·개인화(400~600자) · 유료가 무료의 단순 확장이 아님 · 고객마다 다른 명리 특징 반영 · 모바일 확대 없이 사용(글자 16px↑, 터치 44px↑) · 기존 계산 기능 유지(기존 테스트 전부 통과) · 그래픽·콘텐츠 교체 용이 · 인트로 건너뛰기·다시 보기 · 영상 로딩 실패 시에도 이용 가능.

## 5. 대표 확인이 필요한 것(구현은 계속)
- 인트로 콘티 이미지 재전송 / 영상 파일 납품 형식(권장: MP4 H.264 + WebM, 세로 9:16·가로 16:9 두 벌, 각 8MB 이하, 소리 없는 판 포함)
- 홈(`/`)을 운명비서로 전환하는 시점, 무료 결과 공개(A0)
- 유료 5권 가격·결제 연결 변경(현재 상품·가격 유지)
- 색 겹침(할마카세) 판단
