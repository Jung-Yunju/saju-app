## 1. 무료/유료 구성

### 1-1. 원칙
1. **무료 5장은 그 자체로 완결**한다. 결과를 일부러 끊어 불안을 키우는 구조 금지(지시서 6·10절, CLAUDE.md). 유료는 "무료의 뒷부분"이 아니라 **한 주제를 깊게 다루는 별도 풀이**다.
2. 무료는 AI 비용 0원: 원형 선정·원국·오행 그래픽·십성은 엔진 계산 결과, 문안은 사전 작성한 원형별·구조별 문장 조합 `[추정: 무료 문안이 사전 작성 방식이라는 전제는 작가·백엔드 확인 필요]`.
3. "전통 명리 공식 분류가 아니라 서비스의 창작 상징 해석"이라는 문구는 무료 1장·4장에 상시 표기.

### 1-4. 결제 전환 동선 (공포 유도 금지)
1. 5장 끝(⑤)에서 복자가 "더 듣고 싶은 이야기"를 **주제 카드 5개로 나란히** 제시. 불길한 문구·"지금 안 보면" 표현 금지.
2. 카드 탭 시 **목차 + 첫 문단 + 가격 한 개 + 포함 내역(장 수·재열람 기간)** 을 같은 화면에 표시. 가짜 정가·카운트다운 금지. 첫 구매 할인은 기간·조건을 실제로 지킬 때만.
3. 결제 전 환불·청약철회 사전 고지(법무 확인 필요, market.md §6).
4. 결제 후 생성 대기 화면은 복자 연출, 완료 시 알림. 실패 시 자동 재시도·환불 경로 안내.
5. 측정(출시 후): 입력 시작률, 인트로 건너뛰기율, 5장 완독률, 공유 클릭률, 주제 카드 탭률, 결제 전환율. 전환율 목표 수치는 근거 자료가 없어 **미설정**(§3-4 표는 가설).

## 4. 경쟁 대비 차별점 (1쪽)

**조사 결과(2026-11-27, 검색 1~2회·원문 열람 없음 -> 불완전)**
- 사주 기반 동물·영물 캐릭터를 **앱으로 제공하는 서비스는 못 찾았다.** 확인된 유사 사례: ① 크몽의 주문 제작 서비스 — 생년월일로 일주를 계산해 "수호동물" 카드와 육십갑자 60종 캐릭터 성격 풀이를 PDF로 전달(https://kmong.com/gig/820054 , 검색 요약) ② MBTI 동물상 테스트·성격유형 동물편 앱(사주 아님; https://apps.apple.com/si/app/mbti-%EB%8F%99%EB%AC%BC%EC%83%81-%ED%85%8C%EC%8A%A4%ED%8A%B8/id6472999851 ) ③ 동물 캐릭터로 운명을 보여 주는 오프라인 팝업('운명의 동물', 굴뚝강아지; content-sns #7). 앱스토어 직접 검색과 인스타·틱톡 확인은 **못 했다(확인 필요)**.
- 할머니 페르소나 사주 앱·웹은 이미 5곳 이상(content-sns #2, market.md §7). 따라서 "할머니"와 "동물 매칭" 어느 쪽도 단독으로 새롭지 않다.

**우리만의 축 (모방 없이)**
1. **일주 하나가 아닌 다요소 종합 + 선정 근거 공개.** 60일주 고정 매핑 카드와 달리 일간·월령·강약·용신·조후·합충 등을 종합하고, "왜 이 존재인지"를 4장에 보여 준다. 같은 사주는 같은 결과(결정론).
2. **계산은 코드가 검증.** 범용 AI의 만세력 계산 오류가 반복 지적되는 시장에서(market.md §6) 신뢰 서사가 된다. "정확도 ○%" 같은 광고는 쓰지 않는다.
3. **좋은 말만 하지 않는다.** 그림자·성장 과제를 같은 비중으로 제시. MBTI 동물상류의 일방적 귀여움과 구분.
4. **창작 상징임을 정직하게 표기**(전통 공식 분류 아님) + 확정 예언 금지. 불안 마케팅과 구분.
5. **세계관 일관성**: 원형 이미지·테마·복자·할머니 이야기가 하나의 고급 일러스트 세계. 이미지 품질이 곧 차별점이므로 §3-2 투자의 근거가 된다.
6. **두 영물의 관계 서사**(궁합): 점수가 아닌 "두 존재가 만나면 일어나는 이야기".
- 하지 않을 것: 60일주 카드·MBTI식 16유형 모방, 타 서비스 캐릭터·문구 참조, 전생·미래 배우자 얼굴 등 자극 장치.
- 위험: 영물 테스트는 모방이 쉽고 기술 장벽이 낮다. 방어선은 **근거 공개·품질·콘텐츠 깊이·브랜드**이며, 선행 서비스 존재 여부는 앱스토어·SNS 직접 확인 후 확정(사람이 해야 할 일).
