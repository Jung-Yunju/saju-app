# 디자인 가이드 [현행 기록 + 방향 제안]

> 디자인 실장 투입(5단계) 전까지는 현행 기록과 방향만 둔다.

## 1. 현행 [현행]
- 메인: 짙은 남색 그라데이션(#060818 → #0d1535) + 금색(#c9962a, #d4a847), 별 배경, 장식 한자 「命」
- 글꼴: Noto Serif KR(제목), Noto Sans KR(본문) — `src/app/layout.tsx`
- 입력·결과 화면: 밝은 베이지(#ece7df) 바탕 + 남색 글자(#1b2a3a)
- 결과 화면: 슬라이드형 리포트(표지·목차·장·갈림길·연도·마무리) — `ReadingViewer.tsx` 932줄
- 색·간격이 각 파일에 직접 쓰여 있음(토큰 없음) → 5단계에서 토큰화

## 2. 브랜드 방향 [제안]
- 키워드: 고급스러움 · 신비로움 · 친근함 · 재치
- 피할 것: 붉은 부적·태극 남발·금박 클리셰, 무료 운세 사이트식 배너, 이모지 남발
- 캐릭터: 할머니(풀이하는 사람), 턱시도 고양이 복자(조수·분위기 메이커). **이름·관계는 대표 결정 대기**(현행 코드는 할머니를 '복자할미'로 부름)
- 모바일 우선(375~430px), 터치 영역 44px 이상, 본문 대비 WCAG AA

## 5. 가상 사무실 (O-02) [현행 — 디자인 실장 2026-11-27]
대표 전용 비공개 화면(`office/`)의 픽셀아트. 고객 사이트와 분리돼 있지만 브랜드 톤은 같다. 형식 규격은 `office/CONTRACT.md` 6절.

- 파일: `office/web/art.js`(그림 전부, `window.OFFICE_ART`) · `office/web/map.js`(지도, `window.OFFICE_MAP`) · `office/web/art-preview.html`(확인용, 게시하지 않음) · `office/web/check-art.mjs`(형식 검사, `node office/web/check-art.mjs`)
- 화풍: 위에서 내려다보는 2D 픽셀아트, 한 타일 16px, 화면에서는 정수배 확대. 외곽선은 순검정이 아닌 먹색 `#1b1b24`. 기존 게임의 캐릭터·타일을 참고하거나 복제하지 않은 독자 도안.
- 만드는 방식: 외부 이미지 없이 art.js 안의 문자 도안 + 작은 그리기 함수로 만든다. 팔레트 문자는 색이 처음 쓰일 때 자동 배정(현재 84색, 남은 문자 5개 — 색을 더 늘리기보다 기존 색을 재사용할 것). 색을 바꿀 때는 art.js 1절 `C` 표만 고친다.

### 5-3. 방 배치(36×24 타일)
```
 y0  ████████████████████████████████████  벽
 y1  [대표실 x1-10][명리학 연구실 x12-22][디자인실 x24-34]  ← 벽 앞면(창·책장·달창·무드보드)
 y2-8  남색 카펫        한지 돗자리             밝은 나무
 y9  ─────문(6)──────────문(17)──────────문(29)────
 y10-12 복도(돌 타일). 정문 = 왼쪽 끝 (0,12), 들어서는 칸 spots.door (1,12)
 y13 ─────문(7)──────────문(20)──────────문(30)────
 y14 [개발실 x1-13][회의실 x15-24][휴게실 x26-34]  ← 벽 앞면(화이트보드·시계·선반)
 y15-22 나무 바닥      남색 카펫        나무 + 한지 깔개
 y23 ████████████████████████████████████
```
- 자리(의자 칸, 모두 facing down): 대표 (5,3) · 총괄실장 (2,6) · 사업기획 (8,6) / 엔진 (3,16) · 프론트 (9,16) · 백엔드 (3,20) · 품질검증 (9,20) / 연구소장 (15,4) · 개인화 (19,4) / 디자인 (29,5) · 콘텐츠 (32,5) / 손님 방석 (34,18).
- 회의 spot 8 = 회의 탁자 위·아래 의자, 휴게 spot 8 = 소파 3 + 방석 3 + 조리대 앞 2. 결재 벨 spots.ceoBell = 대표 책상 오른쪽 (6,4).
- 복자 경로 3개: 휴게실 침대↔대표실 침대, 개발실↔회의실, 연구실↔디자인실.
- 가구는 모두 16×16 조각(2칸 이상 가구는 `_l/_m/_r`, `_top/_bot` 조각으로 나눔) → 지도의 한 글자 = 한 타일. 통행 격자는 map.js가 바닥·가구 종류로 자동 계산.
