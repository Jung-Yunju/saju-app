## 1. 이름 짓는 규칙
1. **메뉴 이름에 일반 사주 사이트 낱말을 그대로 쓰지 않는다**: 운세, 오늘의 운세, 신년운세, 평생운, 정통사주, 재물운, 애정운, 연애운, 결혼운, 토정비결, 무료사주, 궁합풀이.
   - 단, 검색에 걸려야 하므로 **부제·설명에는 일반 낱말을 한 번 넣어도 된다**(예: 부제에 "궁합").
2. 할머니의 비유 창고(운명비서판: 서재·책·등불·밤·계절·날씨·물길·길)에서 고른다. 메뉴끼리 비유가 너무 섞이지 않게, 묶음별로 비유를 맞춘다. 수선·옷감·바느질·치수 비유는 쓰지 않는다(폐기된 「수선집」, voice-guide §5). (이전 판: "수선·옷감·부엌·장보기·날씨·길")
3. 공포·미신 낱말 금지: 액, 살풀이, 점괘, 신점, 부적, 대박, 흉.
4. 수명 연상 금지: "여든 해", "평생 끝까지" 같은 표현은 쓰지 않는다.
5. 성별 고정관념 금지: 시집·장가, 신랑감·신붓감.
6. 화면에서 두 줄을 넘지 않게: 이름 12자 이내, 부제 30자 이내.
7. ★ = 작가 추천안.
