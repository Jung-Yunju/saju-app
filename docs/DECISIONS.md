## 대표 결정 대기 목록
1. 1단계 산출물(조직·규칙·현황판) 승인 — D-001~D-005, D-007, D-008
2. **배포 시 무료 풀이 운영 방식(D-014)**: (가) 결제 연결 전까지 새 풀이 생성 중단 / (나) 운영 환경변수 ALLOW_FREE_READING=true + 하루 한도로 무료 유지. 설정 없이 배포하면 (가)가 된다.
3. GitHub 저장소 비공개 전환
4. 할머니 캐릭터의 이름 (복자는 고양이로 확정 — D-015)
5. 23시대 출생 처리(D-013): (가) 23시부터 다음 날(잠정 기본값, 일관적) / (나) 자정에 날짜 변경 = 야자시(현행 서비스 방식). 연구소장 추천: (가) + 해당 출생자에게 두 결과 안내
6. 용신 표시: (가) 하나만 / (나) "힘으로 보면 ○, 계절로 보면 ○" 나란히 (연구소장 추천)
7. 가족관계 해석: 기본 풀이에서 성별에 따라 의미를 바꾸지 않고, 옛 해석은 "전통 해석 보기"에서만 (연구소장 추천)
8. 고전 원문·천문연구원 원문 대조를 위한 클라우드 환경 접속 허용: ctext.org, zh.wikisource.org, koreascience.or.kr, astro.kasi.re.kr (무료, 비용 없음)
9. 백업 태그 업로드, Neon 백업·환경변수 별도 보관(대표 계정)
