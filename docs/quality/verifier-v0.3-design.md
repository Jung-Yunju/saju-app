# 풀이 자동 검증기 verify@0.3.0 설계 메모

- 작성: 품질검증·보안 담당자, 2026-11-27(야간). 대상: `src/engine/verify/**`
- 배경: 2차 블라인드 검토 불합격(`docs/quality/verifier-review-round2.md`). 새 문장 우회 60건을 모두 놓쳤고, 정상 문단 36건 중 20건을 막았다. 원인은 1차 예문의 낱말을 사전에 더하는 식으로 고친 것이다.
- 이번 원칙: 예문을 맞추지 않는다. 사전 대신 **짜임(구조)** 으로 판정한다. 결정론적으로 할 수 있는 것(간지·십성·연도)은 남김없이 잡는 것을 목표로 한다.
- 공개 저장소 기준으로 썼다. 아직 지나가는 우회 문장은 적지 않는다.

## 1. 정확성 검사 — 사전이 아니라 구조로

### 1-1. 간지 언급 추출 (`mentions.ts` `findMentions`)
- 문장 속 천간·지지 언급을 꼴과 상관없이 하나의 "언급"으로 뽑는다.
  - 한자 한 글자·기둥: 甲, 丙午
  - 오행이 붙은 꼴: 甲木, 丙午火, "甲 木"(띄어 씀)
  - 괄호 병기: 갑(甲), 甲(갑), 갑목(甲木), 병오(丙午)
  - 한글 오행 읽기: 갑목, 경금
    - 읽기 표는 계산으로 만든다(글자의 오행과 붙은 오행이 맞을 때만).
    - 일반어와 겹치는 정화·계수·자수·해수·묘목·사화·인목은 '약한 언급'이다. 십성 이름에 바로 붙을 때만 쓴다.
  - 자리 이름: "일간 경", "월지 사"처럼 자리 뒤에 한글 한 글자를 쓴 꼴. 자리 이름만 쓴 "월지는 편관"은 원국의 실제 글자로 바꿔 넣는다.
- 겹치거나 괄호로 이어진 언급은 하나로 합친다. 예) "경금(庚金)"은 언급 하나다.

### 1-2. 십성 결속 문법 (`bindTenGods`)
- 십성 이름(한자·묶음 이름 포함)과 언급 사이의 글이 작은 문법으로만 채워졌을 때 둘을 묶는다. 그 문법은 조사, 꾸밈말, 괄호, 오행 한자, "곧·바로·너에게" 같은 말이다.
- 기준틀은 건너뛴다. "庚 일간에게", "庚金인 너에게", "나(庚金)에게"는 묶을 대상이 아니라 기준이다. 일간 글자가 문장에 있어도 검사를 멈추지 않고 그 앞의 언급에 묶는다.
- 결속의 세 꼴
  - A(글자→이름): "丙火는 편관", "辛金과 酉金은 겁재"(나열도 함께 묶는다)
  - B(이름→글자): "정관인 午", "편관(丙)", "편관은 丙이다"(뒤에 서술격이 올 때만)
  - C(주제-설명): "午火는 너를 다듬는 불이라 정관이다"처럼 이름 뒤에 서술이 오고, 앞쪽 가장 가까운 주제 언급에 묶는 꼴. 일간이 주제이고 비견·비겁이 아니면 묶지 않는다.
- 판정은 규칙 엔진(rules)의 십성과 대조한다.
  - 겉 글자 기준과 맞으면 통과, 지장간·다른 학파 기준으로만 맞으면 info, 어느 기준과도 안 맞으면 block.
  - 기둥은 천간·지지 어느 한쪽이 맞으면 통과한다.

### 1-3. 연도 ↔ 간지 결속 (`timing.ts` `yearRefs`, `checks/basis.ts` `yearGanzhiBindings`)
- 연도 표현
  - 절대 연도
  - 상대 연도: 올해·내년·후년·작년·재작년. 사실표의 올해(this_year)를 기준으로 환산한다.
  - 지시어: "그해"는 앞에 적은 해, "이듬해"는 앞에 적은 해 +1.
- 결속 문법
  - 연도 뒤: 조사·쉼표·괄호·"곧/즉"·"의 간지는"·"에 들어오는"
  - 연도 앞: "丙午년인 2027년", "병오년(2026)"
  - 한글 간지를 접미어 없이 쓴 꼴("2030년은 경술이다")은 서술격·문장부호가 뒤따를 때만 센다. "2030년 임신"(일반어) 같은 오검출을 피하려는 것이다.
- 묶인 간지는 연도→간지 계산값과 항상 대조한다. 그 간지가 올해·대운 기둥에 있어도 면제하지 않는다.
- "X 대운"으로 묶이면 그 해가 X 대운 기간 ±1년 안인지 본다(rule `daeun-year`).
- 예외
  - 입춘 전 출생: 원국 연주가 전년 간지인 경우
  - "1월·정월" 표지가 있을 때의 전년 간지
  - 대운 이름 뒤의 연도("대운은 정축, 2023년부터")

## 2. 금지 주제 시기 예언 (`harm.ts`, `checks/forbidden.ts`)
- 해로운 사건의 의미 범주(낱말 목록이 아니라 짜임)
  - 죽음: 직접 표현 / 완곡어(길을 떠나다·하늘로 가다·눈을 감으시다·명이 다하다) / 나이 + "넘기지 못하다" / 가족 + 잃다·여의다·떠나보내다 / 상(喪)을 치르다·흰 옷
  - 질병·수술: 신체 부위 + 나쁜 상태(무거운 것·가벼운 것을 나눈다), 병원 신세·수술대·칼을 대다·앓아눕다, 병명
  - 관계 파탄: 배우자 + 헤어지다·남남·등을 돌리다, 부부의 연이 다하다
  - 재산 손실: 재산·집·가게 + 날리다·경매·문을 닫다, 망하다·빚더미
  - 사고: 사고가 나다·차에 치이다·크게 다치다
- 동사 활용형은 한글 음절 계산으로 만든다(`hangul.ts`). 예) 갈라서 → 갈라선다·갈라설·갈라섰.
  - 일치한 끝 음절의 받침으로 어미(ㄴ다·ㄹ 것·ㅆ다)를 복원해 양태를 판정한다.
- 서술 양태(그 낱말을 다스리는 서술어로 판정)
  - 단정: ㄴ다·게 된다·팔자다·수가 들었다
  - 가능성: 수 있다·ㄹ지도 모른다·조심해라
  - 그 밖: 부정("~ㄹ 일은 없다") / 조건("아프면") / 걱정("~ㄹ까 봐") / 불확실("~ㄹ지는 모른다") / 인용 반박("~다는 말은 믿지 마라") / 과거 / 지난 일 추정("~었을 것") / 되짚기("~했다고 했지", "네가 말한") / 주제어("이혼 이야기")
  - 단정 맺음으로 바로 끝나면 뒤에 메타 말이 붙어도 단정이다.
  - "길지 않다·얼마 남지 않다"처럼 양을 부정한 말은 부정이 아니라 단정이다.
- 시기 표지: 연도·상대 연도·나이·대운·세운·간지 해·"몇 해 안"·"그해"·"머지않아"·달·계절. 같은 문장에 있거나, 지시어·연결어로 이은 바로 앞뒤 문장에 있으면 시기로 본다.
- 판정 표

| 양태 | 시기 있음 | 시기 없음 |
|---|---|---|
| 단정 | block | 죽음·병명·무거운 사건은 block, 가벼운 사건은 warn |
| 가능성 | 무거운 사건은 block, 가벼운 사건 + 권유(조심해라)는 통과, 그 밖은 warn | 죽음·병명은 block, 무거운 사건은 warn |
| 불확실("~ㄹ지는 모른다") | 무거운 사건이면 warn | 통과 |
| 지난 일 추정 | 죽음이면 block, 그 밖은 warn | 죽음이면 warn |
| 과거 단정 | 무거운 사건이면 warn | 통과 |
| 부정·조건·걱정·인용 반박·되짚기·주제어 | 통과 | 통과 |

- 관용구·비유("죽을 맛", "목숨 걸고", "간이 크다", "가슴이 아프다", "마음을 다치다", "사고방식", "죽마고우", "요절복통")와 간지 한글 읽기("병오(丙午)", "병자년", "병화")는 먼저 가린다.

## 3. 위기 신호 (`checks/crisis.ts` `assessCrisis`)
- 이 검사는 고객 안전의 **최후 방어선이 아니다**. 사전·점수 밖 표현(은유, 외국어, 이모지, 맥락에만 드러나는 위기)은 못 잡는다.
- 명시 표현은 10점이다. 간접 신호는 묶음마다 가장 높은 점수만 더한다.
  - 5점: 깨지 않는 잠, 작별·주변 정리, 기한("~까지만 살")
  - 4점: 사라짐, 끝냄, 짐·민폐·존재 부정, 자기 해침
  - 3점: 살기 싫음, 다 놓고 싶음, 수단 + 의도, "~까지만 버티"
  - 2점: 희망 없음
  - 0.5점: 지침·우울 같은 일상 고민. 다른 신호가 있을 때만 더하고, 이것만으로는 1.5점을 넘지 않는다.
- 점수를 낮추는 경우
  - 대상이 일·관계·회사인 경우("이 관계를 끝내고 싶어요")
  - 여행·잠깐("어디론가 훌쩍 사라지고 싶어요")
  - 처지 불만("이렇게 살기 싫어요")
  - 명시 표현의 자기 부정·과장("죽고 싶은 건 아니고", "죽고 싶을 만큼 창피") → review
- 등급
  - **crisis(4점 이상)**: 풀이를 멈추고 상담 안내만 보낸다. 지키지 않으면 block.
  - **review(2점 이상)**: 중간 등급. 풀이는 나가되 상담 안내를 덧붙이고 사람이 검토한다. 안내가 없으면 warn.
  - none: 해당 없음.
- 보고서에 `coverage.crisisLevel`과 `review.needed/reasons`를 싣는다. 사용자 글 원문은 싣지 않는다(발췌 12자 이하, 신호는 묶음 id로만).

## 4. 그 밖의 검사
- 고전 인용
  - 출처를 사람(목록 밖 인물명·"청나라의 한 학자"·한자 이름 + 曰)과 문헌 꼴("어느 명리 책", "옛 가결")로 넓혔다.
  - 인용 맺음은 말하다·이르다·적다·전하다·가르치다·노래하다·부르다의 활용 전체로 본다.
  - "○○에 따르면"처럼 서명에 내용을 붙이는 출처 주장도 block이다.
  - 통과: 속담·옛말(한문 구절이면 warn), 한글 읽기를 붙인 사자성어, 옛 말을 걷어 내는 대조("~고 했지만 지금은"), 한두 낱말 용어 강조('용신'은).
- 과학·정확성
  - 근거 명사(통계·데이터·논문·"수천 명") + 입증 서술(뒷받침·밝혀·맞아떨어)
  - 정확성 부사(어김없이·십중팔구·빗나간 적 없다·족집게) + 맞힘 서술. 주어가 풀이·사주일 때만 본다.
  - 학문 지위 주장("과학이나 다름없다")
  - 예외: 바로 뒤 부정·질문·인용
- 도덕·성별
  - 성별 일반 명사 + 당위("~해야 한다", "모름지기") 또는 성품 판정
  - 여자 사주 + 글자 조건 + 남편·과부 결과
  - 팔자 + 나쁜 평가 형용사
  - 관계어 + 복·덕 + 모자람
  - 가족을 해치는 팔자
  - 판정을 따옴표로 "표현의 예"로 든 문장은 info다.
- 바넘: 근거 글자를 부르는 말("庚金인 너는")로만 끼운 상투 문장은, 그 꾸밈을 지운 뒤 근거가 남지 않으면 warn이다.
- 사용자 사실
  - 나이 표현(출생 연도 = 첫 대운 시작 연도 − 시작 나이, 만 나이·세는 나이 둘 다)
  - 연도 왜곡(같은 사건을 ±5년 안의 다른 해로 쓰면 warn)
  - 연도 메아리(사실의 해 + 지난 일 단정)
  - 동의어 묶음 확장
  - 출처를 밝힌 되짚기("네가 말해 준 대로")는 맞히기가 아니다.

## 5. 한계 (정직하게)
- 금지 주제·위기·고전·도덕·바넘은 여전히 **어휘와 문법 규칙**이다. 의미 범주를 넓히고 양태를 구조로 판정했지만, 사전에 없는 은유·신조어·비유, 여러 문장에 걸친 함의, 외국어·이모지는 지나간다.
- 십성·연도 간지는 결속 문법이 덮는 꼴에서는 결정론적으로 다 잡는다. 문법 밖의 먼 결속은 묶지 않는다(오탐을 피하려고 일부러 정한 것).
  - 먼 결속 예: 언급과 이름 사이에 동사 절이 끼고, 서술 맺음도 없는 경우
  - 기둥의 한쪽 글자만 맞으면 통과시키는 것도 의도적인 관대함이다.
- 자체 회귀(`tests/verify/round3-self.test.ts`)는 규칙을 아는 작성자가 쓴 문장이라 통과율이 실력보다 높다. 실제 성능은 다음 블라인드(3차) 검토로만 잴 수 있다.
- 실제 AI 출력 기준 오탐률·미탐률은 **미검증**이다.

## 6. 2층 방어 — 대표 결정 필요 (선택지·비용·위험만 적는다. 결정하지 않았다)

| 선택지 | 내용 | 비용 | 위험·개인정보 |
|---|---|---|---|
| A. 사람 검토 | `review.needed=true` 건(위기 review·금지 주제 warn·십성 불확실)만 사람이 출고 전에 본다 | 인건비(건당 수 분 추정, 미측정). 검토 대기만큼 출고가 늦어진다 | 고민 글이 외부로 나가지 않는다. 검토자의 개인정보 접근 권한 관리가 필요하다. 야간·주말 공백 |
| B. 외부 분류 모델(AI 출력만) | 생성된 풀이 문장만 별도 분류 모델로 다시 검사한다(금지 주제·위기 응답 적절성) | 풀이 1건 토큰 수 × 모델 단가(계약 시점의 공시 단가 확인 필요). 호출 수 증가, 지연 수 초 | 풀이에는 사주 사실과 사용자 사실이 들어 있다. 이미 생성에 쓰는 외부 AI와 같은 곳인지에 따라 개인정보 처리방침 갱신이 필요하다. 분류 모델의 오판도 있다 |
