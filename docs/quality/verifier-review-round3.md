# 풀이 자동 검증기 3차 독립 검토 (verify@0.3.0)

- 검토일: 2026-11-27 · 검토자: 외부 독립 검토(3차) · 대상: `src/engine/verify/**` (수정하지 않음)
- 실행: `npx vitest run tests/verify-independent` 결과 5개 파일 424건 모두 통과. 결함은 `it.fails`로 기록했으므로 통과로 센다. `npx tsc --noEmit`은 오류 없이 끝났다.
- 예문은 `tests/verify-independent/round3.test.ts`에 있다. 이 문서는 공개 저장소에 올라가므로 **우회 문장은 적지 않고 범주와 개수만** 적는다.
- 오염 표시: 작성자는 2차 예문 파일을 열지 않았다. 다만 수정하는 도중에 2차 실패 테스트 이름 17건이 화면에 보였다고 스스로 알렸다. 그래서 2차 세트의 연도·간지, 십성, 상대 연도 정상 문단 수치는 **오염**으로 따로 표시한다. 3차 세트는 이번에 새로 썼고 작성자에게 보여 주지 않았다.

## 판정: 불합격 (일부 범주는 기준 충족)

| 합격 기준(제안) | 3차 결과 | 판정 |
|---|---|---|
| 현실적인 우회 문장 미탐 20% 이하 | 42/88 = **48%** (2차 세트의 오염 안 된 범주 25/46을 합치면 67/134 = 50%) | 불합격 |
| 정상 문장 오탐(block) 10% 이하 | 1/55 = **2%** (2차 세트에 남은 오탐을 합치면 14/89 = 16%) | 3차 세트만 보면 합격, 합치면 기준 초과 |
| 위기 신호 미탐 0건 | 6/8 = **75%** 놓침. 사람 검토로 넘어간 것도 0건 | 불합격 |

- 미탐: 막아야 할 문장을 검증기가 놓친 것. 오탐: 정상 문장을 검증기가 막은 것.
- 판정을 정하는 계산 검사(연도·간지 대조와 십성 대조)는 **기준을 충족**했다. 구조 규칙으로 바꾼 효과가 새 문장에서도 확인됐다.
- 반대로 어휘에 기대는 검사(금지 주제, 위기, 도덕, 과학, 바넘, 사용자 사실)는 새 문장의 절반 이상을 놓쳤다. 설계 문서 5절에 적힌 한계("사전에 없는 은유·완곡 표현은 지나간다")가 그대로 드러났다.

## 2. 새 블라인드 세트(3차)

- 사주 4개를 썼다. 기존 A·B에 새로 E(남, 1972)와 F(여, 2001)를 더했다. 원국·대운·공망·연도 간지·십성은 엔진으로 계산했고, 같은 파일의 "엔진 사실값" 테스트가 그 값을 다시 계산해 고정한다.
- 대조군 7건(뻔한 위반)은 7/7 잡혔다. 검사 틀 자체는 정상으로 돈다.
- 모든 문장은 실제 풀이나 고민 글에 나올 법한 할미 말투로 썼다. 특수 문자나 인위적인 띄어쓰기는 쓰지 않았다.
- 한계: 이 세트를 쓴 사람은 검증기 설계 문서를 읽었다. 실제 AI 출력에서 나오는 미탐 비율은 이 표와 다를 수 있다.

### (b) 오탐: 정상 문단 55건 중 1건을 막음(2%)

| 범주 | 시도 | 막음(block) | warn만 남 |
|---|---|---|---|
| 죽음·질병·사고 주제(예언 아님) | 6 | 0 | 2 |
| 이혼·파산 주제(예언 아님) | 4 | 0 | 2 |
| 위기가 아닌 일상 고민 글, 상담 안내만 보낸 정상 응답 | 7 | 0 | 1 |
| 십성을 맞게 쓴 문단(지장간 포함) | 5 | 0 | 0 |
| 연도·간지를 맞게 쓴 문단(상대 연도 포함) | 5 | 0 | 0 |
| 속담·용어 설명·옛말 | 4 | 0 | 0 |
| 과학 부정 문장, 과학 관련 일상 이야기 | 4 | 0 | 1 |
| 도덕·성별 주제의 정상 문장 | 4 | 0 | 1 |
| 근거를 댄 구체적 문장 | 4 | 0 | 0 |
| 출처를 밝힌 사용자 사실 되짚기 | 4 | 0 | 0 |
| 위로·반박·속담 | 8 | **1** | 5 |

- 막은 1건은 남에게 들은 나쁜 말을 반박하는 문장이었다. 검증기가 이를 팔자 판정으로 읽었다. 2차에서 사용자가 들은 말을 되짚는 문장을 막았던 것과 같은 계열이다.
- warn만 남은 12건 가운데 10건은 바넘 비율 경고였다. 이번 시험은 한두 문장짜리 장을 썼기 때문에 생긴 영향이 크다. 실제 풀이는 장 하나에 문장이 많아서 이보다 적게 나올 것으로 본다. 다만 이것은 미검증이다. 나머지 2건은 사용자가 스스로 한 말을 되짚은 문장에 붙은 도덕 경고 1건과 따옴표를 쓴 속담에 붙은 고전 경고 1건이다.
- 위기가 아닌 일상 고민 글 6건은 위기로도, 검토 대상으로도 잡히지 않았다. 2차의 과잉 탐지(4/4)는 3차에서는 재현되지 않았다.
- 주의: 2차 세트에는 정상 문단 오탐이 아직 12건 남아 있다. 낱말 경계, 부정이나 반박 문장, 사용자 말 되짚기에서 나온다. 3차의 정상 문단이 2차보다 쉬웠을 수 있으므로, 오탐률은 두 세트를 합친 16%도 함께 봐야 한다.

## 3. 가장 위험한 미탐 3범주

1. **위기 신호(간접 표현)**: 6/8을 놓쳤다. 놓친 건은 점수가 0이라 사람 검토(`review.needed`)로도 넘어가지 않고, 상담 안내 없이 풀이 전문이 나간다. 고객 안전과 바로 이어지는 범주다.
2. **이혼·파산 시기(완곡 표현)**: 7/8을 놓쳤다. 서비스가 하지 않기로 한 단정 예언이 연도와 함께 자연스러운 말투로 그대로 나간다.
3. **죽음·질병·사고 시기(완곡 표현)**: 8/20을 놓쳤다. 가족 장례, 정신 질환, 몸이 기능을 잃는 표현, '사고'라는 낱말이 들어간 문장까지 지나간다. 2차(21/21 미탐)보다는 크게 나아졌지만 여전히 기준과 거리가 멀다.

그다음으로 위험한 범주는 도덕·성별 판정(5/7)이다.

## 4. 권고 (대표 결정 필요)

- 계산 검사(연도·간지, 십성)는 출고 기준으로 쓸 만하다. 남은 과제는 설계상 관대함 하나다. 겉 글자에 오행을 붙여 쓴 꼴에서 지장간 기준으로만 맞으면 지금은 info를 낸다. 이를 warn 이상으로 올릴지 정해야 한다. 이것은 명리 해석 기준이라 명리학 연구소장의 의견도 필요하다.
- 어휘 검사 범주는 세 번 연속으로 새 문장에서 미탐률 40~100%가 나왔다. 사전과 문법 규칙을 넓히는 것만으로는 기준(20%)에 닿기 어렵다고 판단한다. 설계 문서 6절에서 말한 두 번째 방어층(사람 검토, 분류 모델 등)을 정하는 것이 먼저다. 이것은 비용과 개인정보가 걸린 문제라 대표 승인이 필요하다.
- 위기 신호에는 생성 단계에서 막는 지시를 강화하고, 고민 상품 화면에 상담 안내를 늘 보이게 하는 것(설계 6절의 E)을 바로 하기를 권한다. 검증기로 0건 미탐을 보장할 수 없다.
- 검증기만으로 출고 안전을 보장한다고 보고하면 안 된다.
- 다음 검토(4차)도 이번 예문을 작성자에게 보여 주지 않은 상태에서 해야 한다. 작성자가 수정할 때 이 테스트 파일을 실행하면 실패 이름이 노출된다. 이를 막으려면 독립 세트를 실행에서 따로 떼어 두는 방식을 정해야 한다.
